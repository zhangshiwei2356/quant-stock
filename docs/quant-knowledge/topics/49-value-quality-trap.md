# 49 · 价值陷阱与质量过滤

对照 ERRATA E88–E89；衔接 [03](03-stock-selection.md)、[10](10-factor-selection-corrections.md)。

## 1. 价值陷阱

「便宜」常因基本面恶化、竞争失败或会计地雷。纯低 PE/PB 选股易系统性买进劣质便宜货。

## 2. 质量作滤网

文献常用 **毛利率质量**（如 Gross Profit / Assets，Novy-Marx）：靠近利润表顶端，相对净利润/ROE 少一层操纵空间。  
与价值因子相关性低甚至为负 → 适合交叉：便宜 ∩ 高质量。

## 3. 对比错法

| 错 | 对 |
|----|----|
| 只排序估值 | 估值 × 质量（或现金流质量） |
| 只买高 GP/A | 易买贵成长；质量作滤或互补 |
| 用修订后财报无公告日 | PIT（接 [44](44-universe-pit-survivorship.md)） |

## 4. 本应用

主池偏技术趋势；若研发基本面腿：**禁止裸低估值进金叉引擎**。质量/估值沙箱独立，经中性化与 WFA 后再谈合成。  
应计/造假红旗减法：[52-earnings-quality-fraud.md](52-earnings-quality-fraud.md)。
