# 168 · 风险预算软硬分层

对照第十一万轮 AD29–AD33、AD95；衔接 [50](50-batch6-audit-ops.md)、[76](76-kelly-fractional-sizing.md)、[07](07-map-to-this-app.md)。

## 1. 核心错误

软硬不分；超限仍下单；预算权重海选；预算分改开仓方向；软预算冲破硬风控。

## 2. 改法

硬约束（涨跌停拒单、账面80、单票30、Kill）不可破；软约束可降权/延迟；预算预注册+样本外；**只调仓位不调金叉方向**。

## 3. 本应用

硬风控优先于任何预算优化；冲突以代码/`rules.html`为准。
