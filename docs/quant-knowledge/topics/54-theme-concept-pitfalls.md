# 54 · 题材 / 概念股陷阱

对照 ERRATA E97–E98；衔接 [26](26-limit-up-board-pitfalls.md)、[37](37-portfolio-heat.md)、[29](29-paradigm-matrix.md)。

## 1. 范式冲突

题材热度 + 龙头涨停是**情绪短线**范式；本应用主路径是**趋势金叉波段**。混装 → 涨停成交幻觉、T+1、打板拥挤一并复发。

## 2. 数据坑

概念成分常事后编制。用「今天的概念名单」回填历史热度 = **前视**。无 as-of 概念数据 → 不做历史热度回测，或只做标注研究。

## 3. 允许的用法

- **Heat 聚类**：同题材暴露上限（账户层）  
- **独立沙箱**：明确打板/情绪策略，出门条件另列  
- **禁止**：概念热度作为金叉开仓必要条件或替代 MA 信号  

## 4. 本应用

`OpenFilter`/池扫描保持技术与流动性门槛；题材标签若引入，优先服务 Heat，不服务打板成交假设。
