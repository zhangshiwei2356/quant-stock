# 156 · 信号融合闸门

对照第十万轮 AC01–AC06、AC35、AC41；衔接 [142](142-indicator-confirm-pitfalls.md)、[114](114-multifactor-selection-pitfalls.md)、[29](29-paradigm-matrix.md)。

## 1. 核心错误

多信号简单相加；同质信号叠权；权重海选；融合分静默改金叉方向；黑箱不可解释。

## 2. 改法

显式闸门（AND/OR/元标签式滤）；相关监控；预注册权重+样本外；**只滤不开**；贡献日志。

## 3. 本应用

融合属确认/滤镜层；主路径仍为 MA5/MA20 金叉 + RSI 滤。
