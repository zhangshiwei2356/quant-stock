# 200 · 结构突变与长记忆混淆

对照第十六万轮 AI09–AI12、AI27、AI91、AI96；衔接 [158](158-signal-drift-monitor.md)、[115](115-alpha-decay-regime.md)、[166](166-ashare-stress-scenarios.md)。

## 1. 核心错误

长记忆当突变 / 突变当长记忆；断点事后海选；断点直接改开仓；突变后无冷却/Kill。

## 2. 改法

预注册检验框架（联合/稳健）；断点只触发降仓/冷却/Kill；与漂移监控联动；不改金叉公式。

## 3. 本应用

突变属风控/监控层；金叉主路径锁定。
