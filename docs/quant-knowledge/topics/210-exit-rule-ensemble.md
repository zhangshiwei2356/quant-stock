# 210 · 退出规则组合

对照第十七万轮 AJ21–AJ24、AJ30–AJ32、AJ36、AJ37、AJ65；衔接 [192](192-trailing-time-stops.md)、[184](184-atr-stop-sizing.md)、[191](191-triple-barrier-labeling.md)。

## 1. 核心错误

止损/止盈/时间/信号退出互斥未定义；同 K 多规则打架闪烁；退出条件反改开仓；破 T+1/涨跌停幻想成交。

## 2. 改法

**优先级预注册**（如硬止损 > 时间 > 信号）；与屏障标签对齐；次开确认；制度约束进回测；退出不改金叉开多条件。

## 3. 本应用

退出属风控层；主路径开仓仍金叉+RSI。
