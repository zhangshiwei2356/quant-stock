# 185 · 波动率目标仓位陷阱

对照第十四万轮 AG06–AG09、AG37、AG42、AG96；衔接 [168](168-risk-budget-soft-hard.md)、[50](50-batch6-audit-ops.md)、[178](178-turnover-stamp-tax.md)。

## 1. 核心错误

vol 目标关闭熔断/Kill；估计滞后时加杠杆；撞杠杆/账面硬顶仍加；再平衡推高换手无帽；把杠杆信号当开多。

## 2. 改法

实现 vol 锚定但 **硬风控优先**；杠杆上限+账面80；换手帽；偏离日报；只调仓位规模，不改金叉方向。

## 3. 本应用

vol 目标属定仓沙箱；不可旁路 Kill/单票/总仓硬顶。
