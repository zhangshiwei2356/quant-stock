# 107 · 强化学习交易陷阱

对照第三万轮 V01–V10、V26–V30 等；衔接 [87](87-meta-labeling.md)、[46](46-dsr-pbo-validation.md)、[76](76-kelly-fractional-sizing.md)。

## 1. 核心错误

无成本/无冲击环境；奖励只看收益；Q 值高估；探索过频；奖励塑形偷看未来；黑箱不可解释。

## 2. 改法

训练评测同成本；风险调整奖励预注册；动作掩码（禁自由卖空）；主信号白盒 + RL 仅作次级滤/仓；计 N + 冻结对抗集。

## 3. 本应用

RL **不**替代金叉主路径；沙箱 + 硬顶 + 熔断优先。非投资建议。
