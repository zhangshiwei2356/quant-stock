# 72 · 开盘集合竞价

对照 ERRATA E136–E137、E146；衔接 [05](05-ashare-pitfalls.md)、[16](16-overnight-gap.md)、[67](67-vwap-twap-execution.md)。

## 1. 时段与噪音

| 时段 | 要点 |
|------|------|
| 9:15–9:20 | **可撤单**；虚假挂单噪音高 |
| 9:20–9:25 | **不可撤单**；订单意愿更真实 |
| 9:25 | 撮合生成开盘价 |
| 9:30 | 连续竞价首笔 ≠ 集合价时可差数 bps |

## 2. 常见错误

- 全段订单流当因子（E136）  
- 信号用竞价价、撮合用连续 open 不声明（E137）  
- 竞价涨停价排队「必成」（E146）  

## 3. 研发约束

竞价腿须**显式开关**；因子默认偏 9:20–9:25；fill 标注 auction/continuous。  
**不**把高频竞价打板静默并入日线金叉主路径。

## 4. 本应用

日频金叉默认不依赖竞价微观结构；若加开盘执行，须区分集合价与连续首笔，并保留涨停拒开。
