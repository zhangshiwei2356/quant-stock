# 132 · 截面动量 vs 时序动量

对照 Y36–Y43、Y60；衔接 [129](129-overnight-intraday-split.md)、[115](115-alpha-decay-regime.md)、[124](124-liquidity-adv-filter.md)。

## 1. 核心错误

时序/截面混用；形成期与持有期重叠前视；不跳过近月反转；A 股月频动量消失直接当「无效」；动量池无 ADV。

## 2. 改法

分册开关；标准跳过与 PIT；OC/OV 分解解释；拥挤/成本同测；作池过滤而非改金叉。

## 3. 本应用

动量沙箱；公开美股动量%不可外推。
