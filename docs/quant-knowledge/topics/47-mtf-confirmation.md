# 47 · 多周期确认与金叉噪音

对照 ERRATA E84–E85；衔接 [09](09-entry-exit-corrections.md)、[13](13-regime-switching.md)、本应用 MA5/MA20。

## 1. 核心分工

- **高周期**：定方向（滤）  
- **执行周期**：定触发（金叉等）  
逆势低周期交叉 → 鞭打为主，非「更多 Alpha」。

## 2. 对比

| 做法 | 问题 | 改法 |
|------|------|------|
| 裸金叉 | 震荡反复扫 | +ADX/高周期方向 |
| 只看执行周期 | 逆大势 | 周线/MA60 同向才开 |
| 滤后 IS 变美即上线 | 未计试次 | WFA + DSR（[46](46-dsr-pbo-validation.md)） |

## 3. 与本应用

已有：RSI&lt;60、可选 MA60/ADX。  
研发储备：显式「日线金叉 ∧ 价格&gt;MA60（或周线多头）」作可选门控；**过滤 ≠ 新策略**，须独立验证。  
死叉/高周期转空：可作减仓偏置，勿与打板逻辑混用。
