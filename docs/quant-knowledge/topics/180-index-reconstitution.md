# 180 · 指数调样陷阱

对照第十三万轮 AF13–AF16、AF27、AF34、AF35、AF62；衔接 [159](159-benchmark-selection-pitfalls.md)、[154](154-survivorship-delisting.md)、[128](128-vwap-twap-execution.md)。

## 1. 核心错误

调样名单前视；把「纳入」当买入 alpha；忽略被动资金抢跑与生效后回吐；用最新成分回测历史；调样日无视参与率/涨跌停。

## 2. 改法

公告/生效 **as-of 时钟**；调样事件分册（执行/对冲），非主信号；基准成分历史对齐；调样窗降仓或限参与率。

## 3. 本应用

调样主题不并入金叉；公开调入超额不可外推。
