# 45 · 公司行为与复权分工

对照 ERRATA E79–E81；扩展 [05](05-ashare-pitfalls.md) §3。

## 1. 两套坐标系

| 序列 | 回答的问题 |
|------|------------|
| 不复权 | 当日真实成交价、涨跌停、整手股数 |
| 复权 | 连续收益、均线/波动、绩效累计 |

混用 = 静默错误：拆分日像崩盘触发止损；或用从未出现的「复权价」下单。

## 2. 推荐流水线

1. 信号 / MA / ATR / 收益 → **复权**（或显式公司行为表自算）  
2. 撮合股数、涨跌停、挂单 → **不复权**  
3. 保留累计调整因子，可审计、可重算  

## 3. 分红坑

- **双重复权**：对已调整序列再乘拆分因子  
- **只调拆分不调现金股利**：长样本总收益漂移  
- **成交量方向反了**：流动性过滤失真达数量级  

冒烟：已知大比例送转日，复权收益应接近正常日，不复权价可跳。

## 4. 本应用

对照 `rules`：信号日 K 与 ATR 路径须与复权口径一致；下单映射不复权。差异写入 [07](07-map-to-this-app.md)。
