# 181 · 日内时段效应

对照第十三万轮 AF17–AF20、AF28、AF32、AF63；衔接 [121](121-call-auction-signals.md)、[89](89-overnight-intraday-tug.md)、[05](05-ashare-pitfalls.md)。

## 1. 核心错误

开盘噪声当信号；收盘效应海选窗；时段分直接开仓；集合竞价当连续时段；无视 T+1 日内不可平。

## 2. 改法

时段规则预注册；**只滤不开**；竞价与连续分册；与 T+1/涨跌停同检；样本外计 N。

## 3. 本应用

日频金叉主路径不因 TOD 故事改写；若用分钟线须分册沙箱。
