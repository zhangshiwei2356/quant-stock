# 23 · 动量 / 反转 / 行业轮动纠错

对照 ERRATA E31–E32、E40；衔接 [02](02-strategy-types.md)、[10](10-factor-selection-corrections.md)。

## 1. 周期不要写死成教条

公开与业界常用粗分（**须本地复验**）：

- 偏短窗：反转更常见  
- 偏中期（约 3–12 月）：动量更常见  
- A股：散户、涨跌停、题材 → **行业异质性**大；行业短期动量近年可**翻转为反转**

截面 vs 时序动量的买卖点语义分工见 [62-cs-vs-ts-momentum.md](62-cs-vs-ts-momentum.md)。  

## 2. 错误对照

| 错误 | 改法 |
|------|------|
| 美股 Jegadeesh 窗直接搬家 | A股网格 + 子区间 |
| 动量+反转等权永远开 | regime 切换或正交 |
| 行业动量用当前行业回填 | 时点行业 |
| 忽略涨跌停关注扩散 | 行业内涨跌停集团因子（研究向） |

## 3. 与买卖点

动量/反转多在**选股/行业层**；个股金叉仍是择时。勿把行业轮动信号当日当个股金叉成交。
