# 90 · 高股息与抢权 / 填权

对照 ERRATA E174–E175；衔接 [49](49-value-quality-trap.md)、[86](86-exdiv-dynamic-adj-lookahead.md)、[75](75-pead-earnings-drift.md)。

## 1. 伪高息

股息率 = 股利 / 价格；价格暴跌可抬高股息率 → **跌出来的高息**（E174）。

## 2. 抢权填权

除权前抢权、除权后赌填权依赖情绪与制度，非稳健日频 Alpha（E175）。

## 3. 改法

连续分红年数、分红率、现金流/质量；税后；事件窗单独回测。  
**不**把填权规则并入金叉。

## 4. 本应用

红利因子属基本面沙箱；主路径技术规则不因 XR/XD 简称改信号。
