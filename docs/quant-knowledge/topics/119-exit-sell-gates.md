# 119 · 卖点与退出闸门

对照 W41–W45、W44；衔接 [07](07-map-to-this-app.md)、[38](38-gap-overnight-stop.md)、[96](96-event-driven-clock.md)。

## 1. 核心错误

只优化买点；固定持有 N 日参数扫；盘中完美止损忽略跳空；减仓与金字塔加仓冲突；基本面恶化「当日可知」。

## 2. 改法

买卖对称验证；预注册持有/止盈规则；跳空压力；减仓对齐 50/30/20；披露可知时点 + T+1。

## 3. 本应用

退出规则属上线检查项；与 `rules` 止损/仓位一致优先。
