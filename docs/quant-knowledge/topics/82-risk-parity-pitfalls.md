# 82 · 风险平价误区（股票账户）

对照 ERRATA E155、E160；衔接 [25](25-portfolio-opt-risk-model.md)、[37](37-portfolio-heat.md)、[77](77-correlation-spike.md)、[81](81-volatility-targeting.md)。

## 1. 概念

风险平价（RP）：各资产**风险贡献**相近，常再杠杆到目标波动。  
**≠** 名义等权（E160）。

## 2. 常见错误

- 平静期协方差永久外推（E155）  
- 多资产 RP 模板直接套纯多 A 股篮子  
- 债券对冲假设在股债同跌时失效  

## 3. 股票账户用法

更务实的是：波动倒数加权 / 风险预算 + 行业上限 + Heat；完整 RP 属多资产沙箱。  
压力相关尖峰必须进测试（接 77）。

## 4. 本应用

默认非 RP 引擎；组合层以硬顶与 Heat 为主，RP 仅研究对照。
