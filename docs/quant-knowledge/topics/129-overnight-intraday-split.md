# 129 · 隔夜-日内收益分解（A 股）

对照 Y11–Y20、Y55；衔接 [05](05-ashare-pitfalls.md)、[89](89-overnight-intraday-tug.md)、[132](132-cs-ts-momentum.md)。

## 1. 核心错误

收盘-收盘一体处理；美股「隔夜正溢价」套 A 股；开盘价定义随意；隔夜因子当日开盘前交易；忽略 T+1 导致的日内/隔夜强反转。

## 2. 对比解析

A 股常见叙事：平均隔夜（C2O）偏负、日内偏正；月频动量「消失」常被 OC/OV 反向抵消解释——须分列验证，禁止直接外推海外结论。

## 3. 本应用

分解因子沙箱；最多降权隔夜暴露，**不**静默改金叉；开盘价对齐竞价结果。
