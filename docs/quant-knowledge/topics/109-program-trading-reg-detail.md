# 109 · 程序化交易监管细化（报告与异常）

对照 V11–V20、V31–V35、V81–V84；衔接 [105](105-program-trading-compliance.md)、[97](97-ops-killswitch.md)。

## 1. 制度要点（知识储备）

- **先报告、后交易**（《管理规定》试行；交易所实施细则约自 **2025-07-07** 施行，以现行文本为准）  
- 高频认定（公开口径）：单账户每秒申报+撤单最高 ≥**300**，或全日 ≥**20000**；可差异化收费/额外报告  
- 四类异常：瞬时申报速率、频繁瞬时撤单、频繁拉抬打压、短时间大额成交  
- 北向/深股通：内外资一致监控原则（细则有专章）

## 2. 研发错误

回测不计撤单比/速率；靠幌骗式撤单刷绩效；未建模差异化收费。

## 3. 本应用

合规指标进回测门禁或显式声明缺口；触线联动 Kill Switch。规则以监管最新文本为准。
