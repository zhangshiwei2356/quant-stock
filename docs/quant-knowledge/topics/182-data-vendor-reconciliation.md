# 182 · 多源数据对账

对照第十三万轮 AF21–AF24、AF29、AF38、AF45、AF64；衔接 [163](163-research-reproducibility.md)、[104](104-feature-store-point-in-time.md)、[97](97-ops-killswitch.md)。

## 1. 核心错误

单源盲信；复权/停牌/ST 多源分歧静默；无主源与版本哈希；对账修复直接改信号公式；告警风暴或零告警。

## 2. 改法

主源+校验源；分歧闸（阻断/降级）；配置与源版本哈希；对账属数据门禁，不改金叉；分级告警+冷却。

## 3. 本应用

数据质量门禁优先于任何策略层；冲突以代码/`rules.html`为准。
