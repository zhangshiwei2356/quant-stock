# 89 · 隔夜 / 日内收益分解（A 股）

对照 ERRATA E172–E173；衔接 [16](16-overnight-gap.md)、[72](72-opening-auction.md)、[62](62-cs-vs-ts-momentum.md)、T+1。

## 1. 现象

close-to-close 常掩盖：**同段持续、跨段反转**的拉锯。  
A 股平均隔夜结构常与美股不同，并受 T+1 / 开盘竞价影响（E173）。

## 2. 常见错误

- 只优化收盘收益动量（E172）  
- 照搬美股隔夜溢价做多（E173）  
- 分解 Alpha 无法在可交易时钟落地（今买不能今卖等）  

## 3. 改法

报告拆 overnight / intraday；策略预注册持有哪一段；与跳空/竞价风控联立。

## 4. 本应用

日频金叉默认跨隔夜；若做段内效应须分钟路径 + T+1 状态机，不静默改主引擎。
