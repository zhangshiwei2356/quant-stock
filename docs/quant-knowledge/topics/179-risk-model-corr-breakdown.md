# 179 · 风险模型与相关崩溃

对照第十三万轮 AF09–AF12、AF26、AF36、AF47、AF61；衔接 [166](166-ashare-stress-scenarios.md)、[158](158-signal-drift-monitor.md)、[50](50-batch6-audit-ops.md)。

## 1. 核心错误

静态历史相关；危机时相关→1 被忽略；alpha 与风险因子错位；压力情景用均值相关；相关漂移无监控/Kill。

## 2. 改法

压力相关情景进库；相关结构监控日报；风险模型与 alpha 对齐检查；崩溃触发降仓/Kill，不改开仓公式。

## 3. 本应用

风险层挂风控；金叉主路径锁定。
