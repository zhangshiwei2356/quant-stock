# 62 · 截面动量 vs 时序动量（买卖点语义）

对照 ERRATA E115–E116；衔接 [23](23-momentum-reversal-rotation.md)、[47](47-mtf-confirmation.md)、金叉（TS 类绝对趋势）。

## 1. 定义对照

| | 时序（TS） | 截面（CS） |
|--|-----------|------------|
| 信号 | 相对自身过去 | 相对横截面同伴 |
| 净敞口 | 随涨跌市变化 | 多空常近中性 |
| 典型 | 趋势跟踪、金叉过滤 | Top/Bottom 组合 |

## 2. 错误混用

把「相对最强 TopN」直接当单票金叉买卖点 → 语义错：那是**池构建**，不是入场触发。  
把 TS 组合叫市场中性 → 忽略时变 beta。

## 3. 推荐分工

- **选股/池**：可用截面动量/反转（注意 A 股翻转，见 [23](23-momentum-reversal-rotation.md)）  
- **买卖点**：绝对规则（金叉、破位）或 TS 过滤  
- 跳过近 1 月等实现细节须预注册并计 N  

## 4. 本应用

趋势池粗筛偏 TS；扫描分可含相对强弱，但开仓仍是金叉规则。勿用截面排名替代交叉确认。
