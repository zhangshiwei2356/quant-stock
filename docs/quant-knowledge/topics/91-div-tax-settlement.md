# 91 · 红利税、到账与资金可用

对照 ERRATA E176–E177；衔接 [63](63-fee-regime-turnover.md)、[45](45-corporate-actions-adj.md)、[73](73-closing-auction-afterhours.md)。

## 1. 税与到账

现金红利常按持股期分档征税；到账日 ≠ 除息日。税前立刻入账会虚高（E176）。

## 2. 资金状态

卖出所得是否当日可开新仓取决于清算/券商规则；盲目「当日闭环复用」偏乐观（E177）。

## 3. 改法

费率/税则**按生效日分段**；资金状态机与券商对账；回测报告声明可用资金假设。

## 4. 本应用

对照 `rules.html` 成本与账户；知识库要求红利与清算假设显式，避免静默乐观。
