# 205 · 因子预处理流水线

对照第十七万轮 AJ01–AJ04、AJ25、AJ60、AJ93；衔接 [201](201-industry-class-pit.md)、[114](114-multifactor-selection-pitfalls.md)、[163](163-research-reproducibility.md)。

## 1. 核心错误

顺序颠倒；全样本分位/σ 去极值前视；中性化用现行业；把中性化残差当开仓；流水线无版本哈希。

## 2. 改法

标准顺序：**去极值 → 填充 → 标准化 → 中性化**；统计量截面内 PIT；行业/市值 as-of；配置哈希；只服务选股沙箱，不改金叉。

## 3. 本应用

预处理属特征工程层；主路径仍 MA5/MA20 金叉 + RSI 滤。
