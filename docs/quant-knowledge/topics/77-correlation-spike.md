# 77 · 相关尖峰与压力分散失效

对照 ERRATA E145；衔接 [37](37-portfolio-heat.md)、[30](30-crowding-capacity.md)、[41](41-portfolio-impact.md)、[76](76-kelly-fractional-sizing.md)。

## 1. 问题

平静期两两相关 ρ 偏低 → 名义「分散」；压力期 ρ→1，组合像一笔大单边。  
Kelly/波动目标若用历史均值 ρ，会在最需要减仓时仍过重。

## 2. 常见错误

- 永久外推历史平均相关（E145）  
- 只控单票波动、不控行业/主题/Beta 集中（接 Heat）  
- 回测未加相关尖峰情景  

## 3. 改法

- 压力情景：ρ 上移或因子暴露压缩  
- 硬约束：行业/主题/总 Heat 上限  
- 报告：平静 vs 压力下有效 N（有效独立赌注数）  

## 4. 本应用

Heat 与单票上限是第一道；知识库要求压力相关进资本规划，不替代账户熔断。
