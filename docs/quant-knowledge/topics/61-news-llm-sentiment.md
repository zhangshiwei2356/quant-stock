# 61 · 新闻 / LLM 情绪选股陷阱

对照 ERRATA E113–E114；衔接 [18](18-ml-purged-cv.md)、[46](46-dsr-pbo-validation.md)。

## 1. 核心风险

通用 LLM 训练语料含历史财经与涨跌结果。对**训练截止前**新闻做情绪回测，可能是记忆而非阅读 → **前视**；公司名知识也可造成分心偏差。

## 2. 缓解

- 严格用模型截止日**之后**的样本验收  
- 标题匿名化（去公司名）作稳健对照  
- 新闻时间戳 + 交易日历；默认次日可交易  
- 情绪作特征进已验证模型，勿直连下单  

## 3. 本应用

主路径无 NLP。若开题：独立研究轨；禁止用 ChatGPT 类模型对历史全区间「复盘打分」当绩效。
