# 17 · 事件驱动：北向资金与 PEAD

对照 ERRATA E18–E19。

## 1. 北向资金

- **可用形态**：持股占比变动、净流入、行业轮动残差打分  
- **错误**：把净流入当外生因果直接预测收益  
- **改法**：处理内生性（工具变量/行业内外差异）、周内日历平滑、样本外  

## 2. PEAD / 超预期

常见构件：SUE、公告跳空 JUMP、异常量、分析师上调比例等。

| 错误 | 改法 |
|------|------|
| 报告期末日可用 | 公告日 / 预测可知日 |
| 忽略涨跌停成交 | 漂移期可成交掩码 |
| 高换手不扣成本 | PEAD 对成本敏感 |
| 与 JUMP 等共线硬叠 | 正交化或组合优化约束 |

## 3. 与本应用

当前主路径非事件驱动；属研发开题方向。落地时须接 PIT 财务与公告日历。
