# 48 · A股日历与季节性（研究用）

对照 ERRATA E86–E87；衔接 [16](16-ashare-overnight-auction.md)、[17](17-event-northbound-pead.md)、事件降仓 E70。

## 1. 不要搬美股一月效应

公开研究多提示：A 股公历「一月效应」不稳；更相关的是**农历春节**、财报披露月、月末流动性等——一律当**待验假设**。

## 2. 可研究的结构（非承诺）

| 线索 | 含义 | 用法建议 |
|------|------|----------|
| 春节/长假 | 假期效应常强于普通假日 | 仓位/隔夜约束，非买卖主信号 |
| 财报窗 vs 真空期 | 披露期偏大盘稳健；真空期小盘相对活跃（行业研究） | 风格倾斜，不作金叉替代 |
| 月末 | 流动性/考核相关回报模式 | 换手与冲击预算，非 Alpha 引擎 |

## 3. 错误用法

把月历效应做成每日开平主策略；忽略印花税/冲击；不做衰减检验。

## 4. 本应用

主路径仍是趋势金叉。日历 → 事件降仓/周末隔夜（接 [38](38-gap-risk-stops.md)），或研究报告层风格开关。
