# 66 · ST 状态时点过滤

对照 ERRATA E123–E125；衔接 [44](44-universe-pit-survivorship.md)、[26](26-limit-up-board-pitfalls.md)。

## 1. 陷阱

| 错 | 对 |
|----|----|
| 用今天简称有无「ST」 | as-of ST 状态表 |
| 数据商标签日=公告日 | 交易所公告日决策 |
| 摘帽做成涨幅排行 | 事件驱动；涨停常买不到 |

## 2. 过滤策略

默认：持仓与开仓宇宙排除当时 ST/*ST。  
「摘帽/弱转强」属独立沙箱，须事件链与成交保守假设。

## 3. 本应用

开仓过滤应对齐时点 ST；勿用静态黑名单回填历史。
