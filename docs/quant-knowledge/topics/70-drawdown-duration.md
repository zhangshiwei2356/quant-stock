# 70 · 回撤深度、持续期与恢复

对照 ERRATA E132–E133；衔接 [53](53-bootstrap-drawdown.md)、[12](12-risk-corrections.md)、账户熔断。

## 1. 三件套

| 指标 | 含义 |
|------|------|
| MaxDD 深度 | 峰到谷最大跌幅 |
| 持续期 | 水下多久 |
| 恢复期 | 回到前高多久 |

同深度、不同水下时间 → 可坚持性完全不同。50% 回撤需 100% 涨幅回本。

## 2. 错误

只报深度；把回测 MaxDD 当未来上限；忽略 Calmar/恢复因子。

## 3. 本应用

rules 峰值回撤熔断约 25% 是深度门控。研发报告应同时给持续期；压力用 Bootstrap 分位或 ×1.5 经验。
