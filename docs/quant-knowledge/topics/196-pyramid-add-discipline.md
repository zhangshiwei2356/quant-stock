# 196 · 金字塔加仓纪律

对照第十五万轮 AH22–AH25、AH31、AH32、AH65、AH77；衔接 [07](07-map-to-this-app.md)、[184](184-atr-stop-sizing.md)、[168](168-risk-budget-soft-hard.md)。

## 1. 核心错误

倒金字塔报复加仓；突破 50/30/20；加仓无视原止损 R；摊薄不止损；破账面80/单票30。

## 2. 改法

**正金字塔硬纪律**（本应用 50/30/20）；加仓与止损一体；硬顶优先；禁止亏损摊平报复加；用例验收。

## 3. 本应用

金字塔比例以代码/`rules.html`为准；知识库强调不可被优化/报复加仓静默改写。
