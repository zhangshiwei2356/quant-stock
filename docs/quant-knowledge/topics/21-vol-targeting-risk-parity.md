# 21 · 波动率目标与风险平价纠错

对照 ERRATA E24。

## 1. 波动率瞄准 ≠ Alpha

作用：把风险整形到目标水平。  
副作用：低波期加仓（隐杠杆）→ 波动突增时被动去杠杆 → **顺周期卖压**。

## 2. 风险平价常见错

- 历史协方差在危机失效，相关冲向 1  
- 忽视融资/保证金与杠杆上限  
- 把波动当全部风险（忽略流动性与尾部）  
- 不调仓导致风险贡献漂移  

## 3. 研发检查

- [ ] 最大隐含杠杆是否可接受  
- [ ] 相关=1 情景回撤  
- [ ] 融资成本计入  
- [ ] A股多头约束下「平价」可行性（融券/对冲可得？）  

两融标的、券源与担保约束专深：[59-margin-short-constraints.md](59-margin-short-constraints.md)。
