# 73 · 尾盘集合竞价与盘后定价

对照 ERRATA E138–E139、E147；衔接 [31](31-execution-gap-is.md)、[63](63-fee-regime-turnover.md)、T+1 规则。

## 1. 两套机制

| 机制 | 时间（典型） | 价格 | 成交风险 |
|------|-------------|------|----------|
| 尾盘集合竞价 | 14:57–15:00 | 竞价形成 → 多为日 K **close** | 不可撤；博弈定价 |
| 盘后定价 | 15:05–15:30 | **固定**当日收盘价 | 时间优先排队；可不成交 |

规则会随交易所改革扩展（如盘后覆盖范围变化）；回测须**按生效日分段**，勿写死「仅创业/科创」。

## 2. 常见错误

- 「按 close 市价成交」= 连续段随便成交（E138）  
- 盘后挂单必成；或当日买当日盘后卖（E139 / T+1）  
- 尾盘放量直接当方向 Alpha（E147）  

## 3. 研发约束

收盘执行单独建模；盘后路径要部分成交与可用仓（T+1）联立。  
主路径仍建议：**T 收盘信号 → T+1 开盘（或明确窗口）执行**。

## 4. 本应用

对照 `rules.html` 撮合时钟；知识库不假设盘后必成。制度变更以交易所公告为准，文档只记陷阱。
