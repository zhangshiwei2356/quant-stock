# 03 · 怎么选股

选股回答：「在可交易宇宙里，**相对更值得持有**的是谁？」  
与「何时买」可拆开：先定池，再定入场。

## 1. 三步流水线（推荐心智模型）

### Step A · 硬过滤（可交易性）

至少考虑：

| 条件 | 目的 |
|------|------|
| 非 ST / *ST | 降退市与异常波动风险 |
| 非停牌 | 可成交 |
| 上市天数 > N（如 60–365） | 降次新噪声 |
| 日均成交额 / 换手下限 | 流动性与冲击成本 |
| 涨跌停状态 | 避免「信号有、成交无」 |
| （可选）市值上下限 | 容量与风格暴露 |

### Step B · 特征 / 因子

常见大类（湘财等研报框架）：

1. **估值**：PE/PB 等（注意负值与极值）  
2. **成长**：营收/利润增速  
3. **质量**：ROE、毛利率等  
4. **技术/量价**：动量、反转、波动、换手  
5. **资金**：北向、主力净流入（数据可得性因源而异）  
6. **预期**：一致预期修正（专业数据）

技术面快速筛（开源选股器常见组合示例）：

- RSI 落在「超卖反弹」区间  
- MACD 绿柱收缩  
- 量能相对均量放大  
- 价格站上 MA20  

（具体阈值需回测，不可照搬。）

### Step C · 排序与组合

1. 截面标准化（当日 Z-score），避免量纲碾压。  
2. **先标准化再按标签筛样本**，避免用「未来有没有收盘价」污染截面（ElasticNet 文选强调的信息隔离）。  
3. **中性化纠错**：不要只用「行业内减均值」；应截面回归 `因子 ~ log(市值) + 行业哑变量` 取残差（见 [10](10-factor-selection-corrections.md) / ERRATA E08）。  
4. 合成：等权 / ICIR 加权 / 模型预测 rank。  
5. 取 TopN，等权或约束优化（行业、风格暴露）。  
6. 调仓周期：日/周/月；越频换手与成本越高。

## 2. 因子有效性怎么验

- **RankIC**：因子值与下期收益的截面相关。  
- **ICIR**：IC 均值 / IC 波动，稳定性。  
- **分层回测**：按因子分 5 组，看多空与单调性。  
- **拥挤度**：多空组换手/波动异常升高时需降权（研报常见监控）。

经验阈值（仅作入门参考，非绝对标准）：RankIC 均值与 ICIR 需结合样本与多重检验看待；短周期技术因子易衰减，需定期重评估。

### 2.1 预处理与合成（研报常见流程）

1. **极值**：中位数 ± 3×MAD，或 Winsorize。  
2. **截面 Z-score** 标准化。  
3. **中性化**：对市值、行业回归取残差，降低风格暴露伪装成 alpha。  
4. **合成**：等权 → IC/ICIR 加权 → 模型（Lasso/ElasticNet/树模型）。  
5. **波动升高时**：ICIR 加权往往比纯 IC 均值更稳（指数增强类研报常见结论）。  

组合层还可加：行业偏离、个股权重上限、换手约束、成分股占比（指数增强场景）。

## 3. 「池」与「仓」分离

- **目标池**：扫描后留下的可交易候选（容量有限，如 Top30）。  
- **持仓**：真正买入的子集；移出池 ≠ 立刻卖出（本应用语义）。  

好处：扫描贵、交易贵分离；风控与执行更清晰。
