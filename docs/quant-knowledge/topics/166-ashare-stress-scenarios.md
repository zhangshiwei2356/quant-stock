# 166 · A股压力情景库

对照第十一万轮 AD19–AD23、AD72、AD76；衔接 [154](154-survivorship-delisting.md)、[05](05-ashare-pitfalls.md)、[157](157-capacity-aum-scaling.md)。

## 1. 核心错误

事后挑选美化情景；跌停可卖/涨停可买；零冲击；压力结果反改信号阈值；对外披露美化。

## 2. 改法

**预注册**情景库（踩踏、一字板、ADV 断崖、退市路径）；涨跌停死锁保守成交；容量/参与率硬顶同开；压力只降仓/Kill，不改金叉定义。

## 3. 本应用

压力演练不改生产参数；结果进门禁与 Kill，不进开仓公式。
