# 202 · 节假日薄流动性

对照第十六万轮 AI17–AI20、AI29、AI31、AI47、AI90；衔接 [167](167-liquidity-regime.md)、[193](193-overnight-gap-risk.md)、[157](157-capacity-aum-scaling.md)。

## 1. 核心错误

节前节后满仓满额；日历效应海选当信号；无视 ADV 断崖与跳空；公开月份效应外推。

## 2. 改法

交易日历预注册；薄流动性日 **降仓/禁开/参与率帽**；与缺口规则同开；日历只滤不开。

## 3. 本应用

日历属风控/执行层；金叉主路径锁定。
