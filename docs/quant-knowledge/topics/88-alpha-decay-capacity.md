# 88 · Alpha 衰减与容量

对照 ERRATA E170–E171、E179；衔接 [30](30-crowding-capacity.md)、[56](56-participation-sizing.md)、[46](46-dsr-pbo-validation.md)。

## 1. 概念

- **容量**：再加大 AUM 时净边际利润不再增加（冲击吃掉边缘）  
- **衰减**：拥挤/结构变化使边缘随时间变薄；半衰期可沟通但易噪  

机械因子更易拥挤衰减；判断型因子形态不同（文献分歧，不可当保证）。

## 2. 常见错误

- 样本内夏普外推任意规模（E170）  
- 拥挤择时当 Alpha（E171）  
- 全样本一次拟合 λ 外推（E179）  

## 3. 改法

容量曲线（规模→净收益）；滚动 IC/半衰期看板；拥挤服务**降权/风控**。

## 4. 本应用

纸面/实盘对照规模与参与率；知识库禁止把公开回测当无限容量承诺。
