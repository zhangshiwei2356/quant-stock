# 06 · 仓位与风险管理

买卖点决定「何时」；仓位决定「亏多少」。仓位做错，再好的入场也会爆仓。

## 1. 固定分数风险（Fixed Fractional）

\[
Shares = \frac{Equity \times r}{StopDistance}\quad\text{再取整手}
\]

- \(r\)：单笔愿亏权益比例（常 0.5%–2%）  
- \(StopDistance\)：入场价到止损价的每股距离  
- 优点：每笔 R 清晰，账户缩放自动  
- 弱点：止损距离若未反映波动突变，同一 \(r\) 实际风险不同  

## 2. ATR 波动率仓位

\[
Shares = \frac{Equity \times r}{k \cdot ATR}
\]

- \(k\)：止损 ATR 倍数（趋势跟踪常 1.5–3）  
- 波动大 → 股数自动变少；波动小 → 股数变多  
- 实务：再加「单票名义上限」「总仓上限」双保险  

**示例**：权益 10 万，\(r=1\%\)，ATR=2 元，\(k=2\) → 风险预算 1000 元，每股风险 4 元 → 250 股 → A股取整到 200 股。

## 3. Kelly 与半 Kelly（慎用）

\[
f^* = \frac{p\cdot b - q}{b},\quad q=1-p,\ b=\frac{\text{avg win}}{\text{avg loss}}
\]

- Full Kelly 回撤极大；实务多用 **1/2 或 1/4 Kelly**  
- 胜率/盈亏比来自回测时常高估 → 再打折  
- 更适合「已有稳定样本外 edge」的系统，不宜直接当开仓股数唯一依据  

## 4. 账户层风控（组合级）

| 机制 | 作用 |
|------|------|
| 单日亏损上限 | 防止一日连环开仓放大损失 |
| 连亏冷却 | 策略失效或行情极端时暂停 |
| 峰值回撤降仓 / 熔断 | 大回撤时减杠杆或禁开+清仓 |
| 总仓 / 单票上限 | 分散与容量约束 |
| 市场波动缩放 | 高波动环境整体降仓（海外常用 VIX；A股可用指数波动率代理） |

经验框架（海外文献量级，仅作思路）：低波可略提高单笔 \(r\) 与持仓数；高波降低 \(r\)、加宽 \(k\)、减少同时持仓数。

## 5. 与止损的耦合

仓位公式的分母应与**真实会执行的止损**一致：

- 若止损 = \(2\times ATR\)，分母就用 \(2\times ATR\)  
- 若另有「成本 − 权益×2%/股数」类夹逼，取实际更紧的那条算风险  

## 6. 本应用对照（摘要）

本仓库用「单只上限 30% × ATR 调节 × 回撤仓位系数」+ 账户熔断，不是纯 Fixed Fractional 的 \(r\) 模型。细节见 [07-map-to-this-app.md](07-map-to-this-app.md) 与 `static/docs/rules.html` / `risk.html`。
