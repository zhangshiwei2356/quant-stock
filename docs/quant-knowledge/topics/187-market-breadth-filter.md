# 187 · 市场宽度过滤

对照第十四万轮 AG14–AG17、AG28、AG92、AG94；衔接 [156](156-signal-ensemble-gating.md)、[172](172-factor-timing-vs-selection.md)、[167](167-liquidity-regime.md)。

## 1. 核心错误

宽度当买入触发；阈值海选；与个股信号混量纲；低流动宽度失真仍开仓；与择时双重开仓。

## 2. 改法

宽度 **只滤不开**；预注册定义；低质量宽度降权/禁用；与择时分层；滚动有效性监控。

## 3. 本应用

宽度若启用仅确认/滤镜层；主路径仍金叉+RSI 滤。
