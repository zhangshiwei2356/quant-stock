# 206 · 缺失填充前视

对照第十七万轮 AJ05–AJ08、AJ26、AJ44、AJ61；衔接 [174](174-earnings-calendar-pit.md)、[104](104-feature-store-point-in-time.md)、[154](154-survivorship-delisting.md)。

## 1. 核心错误

全面板全局插补；用未来截面中位数；停牌 ffill 当可交易；训练用测试期统计；行业填充用现分类。

## 2. 改法

仅用 **当时可见** 信息填充（历史截面/当时行业中位数）；覆盖率门禁；停牌标记≠成交；规则预注册并披露。

## 3. 本应用

填充属数据门禁；冲突以代码/`rules.html`为准。
