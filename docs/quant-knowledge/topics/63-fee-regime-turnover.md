# 63 · 费率制度与换手敏感

对照 ERRATA E117–E118；衔接 [20](20-execution-cost-impact.md)、[01](01-quant-fundamentals.md)。

## 1. 印花税等会变

A股卖出印花税等费率历史上多次调整（如 2023-08-28 减半）。全样本固定旧税率 → 成本错；固定新税率 → 高估历史可交易性。

## 2. 做法

- 回测用**分段费率表**（按生效日）  
- 压力测试用更高税率 / 更高佣金  
- 降税后**不**自动提高换手：换手由信号半衰期、容量、冲击决定  

## 3. 本应用

以 `rules.html` 现行费率为准；长历史研究须声明分段假设。高换手策略出门必须费率敏感分析。
