# 10 · 选股因子纠错与稳健流程

扩展 [03-stock-selection.md](03-stock-selection.md)；对照 ERRATA E06–E09。

## 1. 标准流水线（纠错后）

```
可交易宇宙(as-of)
  → 极值处理(MAD/Winsor)
  → 标准化(Z-score)
  → 中性化(截面回归: log市值 + 行业)
  → 合成(等权/ICIR/模型)
  → 组合约束(行业偏离、个股权重、换手)
  → 样本外 / Walk-forward
```

## 2. 价值因子

- 优先 **E/P、B/M**，慎直接排序 PE。  
- 负盈利：剔除或 sign-aware；勿让亏损股「伪便宜」。  
- 财务：**公告日**可用，报告期末不可用。

## 3. 显著性与衰减

- 多重检验：t 阈值远高于 2。  
- 发表/公开后夏普常大幅衰减 → 实盘预期打折。  
- 拥挤代理：持仓市值/流动性越高，衰减路径不同（拥挤 vs 过拟合需分拆诊断）。

## 4. IC 使用纠错

- RankIC + ICIR 优于只看一次 IC。  
- 衰减分析用多起点；警惕 T+1 隔夜噪声。  
- 分层收益须看单调性，不只看多空差。

## 5. 与本应用差距（储备方向）

当前目标池偏技术扫描分；完整多因子+中性化属后续研发储备，非现状。
