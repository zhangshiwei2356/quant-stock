# 86 · 除权息与动态复权未来函数

对照 ERRATA E166–E167；衔接 [45](45-corporate-actions-adj.md)、[05](05-ashare-pitfalls.md)。

## 1. 深化 45

「信号复权 / 撮合不复权」不够：若用**今日动态前复权**回放历史，等于偷看后续分红方案（E166）。

## 2. 常见错误

- 动态前复权全历史回测（E166）  
- 不复权除权日当暴跌止损（E167）  
- 后复权价直接挂单  

## 3. 改法

- as-of 调整因子，或后复权 + 公司行为事件表可重算  
- 权益：股数变化 + 现金红利分列记账  

## 4. 本应用

对照 45 与 `rules`；知识库要求长回测声明复权 as-of 方法，禁止「下载即用的最终前复权」冒充可实施。
