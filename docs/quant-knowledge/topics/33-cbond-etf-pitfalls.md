# 33 · 可转债与 ETF（跨品种储备）

对照 ERRATA E54–E56。**非本应用股票主路径**；开题须独立模块。

## 1. 可转债

- 双低/估值：近年易失效；「极便宜」或是正股恶化  
- **强赎**：高价债按面值附近赎回可巨亏 → 公告与条款监控、到期前清仓  
- **转股套利**：正股涨停可能卖不出 → 涨停熔断、改卖债  
- 回测难：历史转股价/条款需外部 PIT 数据  

## 2. ETF

- 勿追高溢价；看 IOPV 与公告  
- 迷你规模：价差大、冲击大、清盘风险  
- 套利需申赎清单、现金替代、T+1 约束  

## 3. 研发门禁

与股票金叉分仓核算；强赎/溢价为硬过滤。
