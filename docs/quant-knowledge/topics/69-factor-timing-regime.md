# 69 · 因子择时与状态识别

对照 ERRATA E130–E131；衔接 [13](13-regime-switching.md)、[46](46-dsr-pbo-validation.md)、[10](10-factor-selection-corrections.md)。

## 1. 两个概念

| | 因子择时 | 状态（regime）识别 |
|--|----------|-------------------|
| 目标 | 预测未来因子谁强 | 识别切换**已发生**并利用持续性 |
| 风险 | 数据挖掘、关系时变 | 实时确认滞后 |

## 2. 陷阱

海选宏观/情绪指标择时；用修订后宏观；换手吃光择时收益；把 HMM 状态当精确拐点预测。

## 3. 本应用

主路径固定金叉规则 + 可选 ADX/MA60 滤，属轻量 regime，**非**多因子择时引擎。因子择时仅沙箱，须 WFA/DSR 与成本。
