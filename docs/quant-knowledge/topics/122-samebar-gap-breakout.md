# 122 · 同 K 成交、复权与缺口突破

对照 X11–X20、X61–X63；衔接 [05](05-ashare-pitfalls.md)、[38](38-gap-overnight-stop.md)、`rules.html`。

## 1. 核心错误

收盘算信号、收盘成交；未收盘偷价；同 K 止盈止损双触写前即胜；前复权选「便宜老股」；缺口/ORB 参数海选。

## 2. 改法

信号确认 → 次 K 开盘/限价；OHLC 路径不确定取悲观；价量用后复权或不复权口径；缺口/突破沙箱 + 板状态过滤。

## 3. 本应用

金叉/RSI 落地时钟须与代码一致；禁止同 K 完美成交假设。
