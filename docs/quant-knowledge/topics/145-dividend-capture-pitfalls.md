# 145 · 分红捕获策略陷阱

对照 AA24–AA29、AA44、AA55；衔接 [90](90-dividend-yield-trap.md)、[133](133-corporate-action-signals.md)、[124](124-liquidity-adv-filter.md)。

## 1. 核心错误

除息前买入必赚；最终派息额前视；登记/除息/派息日混淆；捕获后必填权；高息小票无 ADV；T+1 当日买卖。

## 2. 改法

预案 as-of；三日期清单；费后+税摩擦验证；ADV 过滤；事件沙箱；禁作主引擎。

## 3. 本应用

分红捕获不替代金叉；伪高息非主路径。
