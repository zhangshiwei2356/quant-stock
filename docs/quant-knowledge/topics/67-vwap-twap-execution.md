# 67 · VWAP / TWAP 执行与验收

对照 ERRATA E126–E127、E51；衔接 [31](31-execution-gap-is.md)、[56](56-participation-sizing.md)、[16](16-ashare-overnight-auction.md)。

## 1. 算法分工

| 算法 | 含义 | 易错 |
|------|------|------|
| TWAP | 时间等权切片 | 薄流动性时段冲击大 |
| VWAP | 跟量曲线 | 自指基准；量预测错则偏 |
| POV | 占成交比例 | 参与率过高仍推价 |

## 2. 验收

**主指标**：Implementation Shortfall（相对决策价）。  
VWAP 滑点只作调度诊断，不作唯一绿灯。大单占比高时「赢 VWAP」可掩盖相对到达价的亏损。

## 3. A股注意

避开开盘静默/薄量窗；随机化切片降被嗅探；参与率夹逼。

## 4. 本应用

日 K 默认次日开盘撮合；大单研发再接切片算法。分钟路径已有开盘静默，与 TWAP 避薄量一致。
