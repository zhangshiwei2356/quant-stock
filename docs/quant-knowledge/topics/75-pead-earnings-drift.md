# 75 · 盈余公告后漂移（PEAD）

对照 ERRATA E142–E143、E149；衔接 [03](03-stock-selection.md)、[48](48-calendar-effects.md)、[52](52-earnings-quality-fraud.md)、[59](59-margin-short-constraints.md)。

## 1. 现象与度量

盈余惊喜后价格常同向漂移一段；经典 SUE/CAR 在部分市场衰减有争议。  
A 股研究亦用隔夜收益等简化惊喜度量（如 ORJ 类），但**含开盘跳空信息**。

## 2. 常见错误

- 按**报告期**而非**公告日**对齐（E142）  
- 照搬美式多空千票组合（E143；融券/成本）  
- 跳空已定价仍当「未交易 Alpha」追入（E149）  

## 3. 研发约束

事件日 = 最早披露/公告日；样本外与费用后检验；偏**多头小篮子**或过滤，不作主买卖引擎。  
注意力分散日（大行情、扎堆公告）漂移更强的文献结论**不可外推**为本系统绩效。

## 4. 本应用

金叉主路径不并入 PEAD；若做事件模块：公告日 PIT + 跳空过滤 + 与解禁/财报窗降权协同。  
分析师修正 / 一致预期时钟见 [79](79-analyst-revision-pit.md)。
