# 173 · ST/*ST 路径 PIT

对照第十二万轮 AE23–AE27、AE40、AE43、AE73；衔接 [66](66-st-pit-filter.md)、[154](154-survivorship-delisting.md)、[05](05-ashare-pitfalls.md)。

## 1. 核心错误

用现名/现状态滤历史；「曾 ST 永久剔除」与「当日 ST」混淆；日切漏戴帽/摘帽；退市路径截断；ST 涨跌幅规则混用。

## 2. 改法

**as-of 日切** ST/*ST 状态；区分当日过滤 vs 历史污点策略；退市池完整路径；涨跌幅按当时规则；过滤解释日志。

## 3. 本应用

ST 过滤属股票池门禁，不改金叉公式；须与幸存者回测同开。
