# 02 · 量化策略范式

策略不是「指标堆砌」，而是对**收益来源（Alpha 假设）**的押注。

## 1. 四大常见范式

### 1.1 趋势跟踪（Trend Following）

- **假设**：价格趋势在一段时间内延续。  
- **典型工具**：均线金叉/死叉、突破前高、ADX 过滤弱趋势。  
- **弱点**：震荡市反复止损（假突破）。  
- **补救**：ADX 阈值、放量确认、降低仓位或暂停开仓。  
- **常见错误**：无 regime 过滤时每根金叉都做 → 见 [ERRATA E02](../errata/ERRATA.md)。

### 1.2 均值回归（Mean Reversion）

- **假设**：价格短期偏离均值后会回来。  
- **典型工具**：布林带、RSI 超卖反弹、Z-score。  
- **弱点**：单边趋势中「抄底抄在半山腰」。  
- **补救**：大周期趋势过滤、严格止损、限制连亏次数。  
- **常见错误**：下跌趋势中反复 RSI\<30 抄底 → 见 [ERRATA E01](../errata/ERRATA.md) / [13](13-regime-switching.md)。

### 1.3 动量 / 反转（横截面）

- **动量**：过去一段时间强者下一段继续强（中期更常见）。  
- **反转**：短期超涨超跌后回归（短周期更常见）。  
- A股量价因子里两者常并存，且**行业/时段会翻转**；须用 IC/ICIR 与子区间检验（深化见 [23-momentum-reversal-rotation.md](23-momentum-reversal-rotation.md)，ERRATA E31–E32）。

### 1.4 多因子选股（Cross-sectional）

- **假设**：多个可解释因子对下期收益有预测力。  
- **流程**：股票池过滤 → 因子计算 → 标准化/中性化 → 合成打分 → TopN → 调仓。  
- **合成**：等权、ICIR 加权、最大化夏普合成、或带正则的线性/树模型（Lasso/ElasticNet）。  

## 2. 策略分层（工程上好维护）

```
L0 硬过滤：ST/停牌/次新/流动性/涨跌停不可成交
L1 选股/排序：因子或评分 → 目标池
L2 择时/入场：均线交叉、突破等
L3 出场：死叉、止损、移动止盈、时间止损
L4 账户风控：单日亏损、回撤、连亏熔断
```

本应用的「目标池 + 分钟扫描」接近 L1+L2 分工。

## 3. 参数与过拟合

- 参数越少越好解释；网格搜索后做 **walk-forward / 子区间**。  
- 「全历史最优参数」往往失效；看参数邻域是否平坦。  
- 多重检验：因子很多时，显著性阈值应收紧（研报/严格回测框架常讨论）。
