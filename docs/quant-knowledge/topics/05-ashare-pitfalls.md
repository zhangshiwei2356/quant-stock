# 05 · A股回测常见坑

> 多数「看起来很赚钱」的回测，输给实盘的原因往往是**数据与成交假设**，不是 alpha 本身不够强。

## 1. 幸存者偏差（Survivorship Bias）

- **现象**：样本只含「今天还活着」的股票，历史上退市、被 ST 长期折磨后退市的标的被抹掉。  
- **后果**：低估极端亏损路径，高估长期持有策略。  
- **工程对策**：用**时点可投资宇宙** `tradable_universe(t)`（含当时未退市、未停牌标的）；指数成分用历史成分，不用「当前成分回填历史」。  
- **变种**：IPO 偏差（只看到活下来的次新）、借壳后同代码不同公司。  
- **专深**：[44-universe-pit-survivorship.md](44-universe-pit-survivorship.md)（三日期契约、退市收益、借壳 PIT）。

## 2. 前视偏差（Look-Ahead）与未来函数

| 类型 | 含义 | 典型例子 |
|------|------|----------|
| 前视偏差 | \(t\) 决策用了 \(t\) 时尚不可得的数据 | 财报按报告期末日可用，实际应按**公告日**（或公告日+1） |
| 未来函数 | 特征计算偷看了 \(t' > t\) | 全样本 Z-score、用整段均值回归、滚动窗越界 |

**Point-in-Time（PIT）**：每条基本面记录绑定（报告期, 版本, 知晓时刻）；回测只读 `知晓时刻 ≤ t` 的最新版。

## 3. 复权陷阱

| 口径 | 用途 |
|------|------|
| 不复权 | 贴近真实挂单价、涨跌停价计算 |
| 前复权 | 看近期形态方便，但**事后前复权**会把未来除权因子注入过去 |
| 后复权 | 连续收益/因子研究更稳 |

经典事故：用「事后前复权」回测，等于提前知道未来送转，均线在除权日附近出现**实盘不存在的金叉/死叉**。

**推荐分工**：信号与收益用后复权或 PIT 前复权；下单价映射回不复权；涨跌停相对昨收用不复权。  
专深：[45-corporate-actions-adj.md](45-corporate-actions-adj.md)。

## 4. 停牌与涨跌停成交

- 停牌期：**不能**按收盘价假装调仓；复牌常跳空。  
- 涨停：买单未必成交；跌停：卖单未必成交。  
- 乐观假设「涨停也能买到」会系统性高估追涨策略。  
- 日线 high/low 可能含「擦边」不可成交价，突破策略要警惕幻影信号。

## 5. 成交与成本假设过松

应显式建模（哪怕简化）：

- 佣金、印花税、过户费  
- 滑点与冲击（与成交额占比相关）  
- 单日成交额占比上限（如 ≤ 当日成交额 5%）  
- 信号日与成交日分离（见 [04-entry-exit.md](04-entry-exit.md)）

## 6. 数据窥视（Data Snooping）

因子/参数在同一段历史上反复试错，显著性虚高。缓解：样本外、walk-forward、多重检验收紧阈值、参数邻域平坦性检查。

## 7. 检查清单（发版前回测）

- [ ] 宇宙是 as-of，不是「今天成分回填」  
- [ ] 基本面/指数成分带知晓日  
- [ ] 特征函数无法读到未来 bar  
- [ ] 复权口径与用途匹配，未混用挂单价  
- [ ] 停牌日不可成交；涨跌停保守成交  
- [ ] 成本与冲击打开；换手不过分  
- [ ] 子区间与参数扰动仍成立
