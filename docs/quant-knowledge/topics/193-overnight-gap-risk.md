# 193 · 隔夜缺口风险

对照第十五万轮 AH10–AH13、AH28、AH42–AH44、AH70；衔接 [89](89-overnight-intraday-tug.md)、[122](122-samebar-gap-breakout.md)、[05](05-ashare-pitfalls.md)。

## 1. 核心错误

缺口当买入信号；跳空按昨收成交；T+1 下「收盘卖开盘买」套利幻想；公开隔夜异象收益外推；忽略涨跌停。

## 2. 改法

缺口成交按 **开盘/竞价/涨跌停**；隔夜因子分册验证非触发；压力含跳空穿价；公开数字不可外推；不并金叉。

## 3. 本应用

隔夜/缺口属风险与执行假设；主路径仍日频金叉。
