# 208 · 因子正交与残差

对照第十七万轮 AJ13–AJ16、AJ28、AJ43、AJ63、AJ98；衔接 [201](201-industry-class-pit.md)、[198](198-sample-uniqueness.md)、[177](177-portfolio-optimization-pitfalls.md)。

## 1. 核心错误

相关因子叠权；正交回归用现市值/行业；自变量前视；残差当开仓；样本重叠未加权。

## 2. 改法

正交自变量 **PIT**；顺序预注册；与唯一性权重同开；残差只进选股分册，只滤不开。

## 3. 本应用

正交属多因子沙箱；不并金叉。
