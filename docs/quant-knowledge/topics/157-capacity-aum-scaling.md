# 157 · 策略容量与 AUM 缩放

对照 AC07–AC12、AC36、AC42、AC48；衔接 [56](56-participation-sizing.md)、[88](88-capacity-alpha-decay.md)、[128](128-vwap-twap-execution.md)。

## 1. 核心错误

小资金曲线外推大 AUM；参与率超约 1%–5% 仍灌单；回测无容量层；扩容不降频；大单无切片。

## 2. 对比解析

容量上限由冲击/滑点决定；经验规则常以 ADV 参与率警示——须容量感知回测与参与率日报，公开他策略容量不可外推。

## 3. 本应用

容量只降仓/降频，**不**改金叉方向；与 Heat/单票顶取严。
