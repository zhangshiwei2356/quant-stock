# 177 · 组合优化陷阱

对照第十三万轮 AF01–AF04、AF25、AF41–AF44；衔接 [168](168-risk-budget-soft-hard.md)、[114](114-multifactor-selection-pitfalls.md)、[07](07-map-to-this-app.md)。

## 1. 核心错误

样本协方差直接求逆导致极端仓；均值微调权重爆炸；无换手/成本；连续权重无视 lot/单票硬顶；优化结果静默改金叉方向。

## 2. 改法

协方差收缩/正则；换手与成本进目标；硬约束（账面80、单票30、lot）优先于优化；优化只产出仓位建议，不开仓方向。

## 3. 本应用

主路径仍金叉+RSI 滤；组合优化属沙箱定仓层。
