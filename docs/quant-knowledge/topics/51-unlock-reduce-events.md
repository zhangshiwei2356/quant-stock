# 51 · 解禁 / 减持事件（选股与仓位）

对照 ERRATA E91–E92、E102；衔接 [17](17-event-northbound-pead.md)、[48](48-ashare-calendar.md)。

## 1. 常见叙事 vs 用法

公开事件研究常描述：**解禁前**因预期抛压偏弱，**解禁后**不确定性落地或出现反弹——异质大（解禁市值占比、股东类型、同期行情），**不作铁律**。

| 错法 | 改法 |
|------|------|
| 解禁日必跌做空 | 分桶事件研究 + 成本后检验 |
| 解禁前无脑抄底 | 可能买在下跌趋势中段 |
| 减持冲击当均值回归加仓 | 事件掩码/降仓，勿当 alpha |

## 2. 时点

须分列 **公告日** 与 **解禁/减持发生日**。回测决策只能用已公告信息。

## 3. 本应用

主路径金叉不依赖解禁。研发：可选「大额解禁窗降仓/禁新开」过滤器；独立事件沙箱勿并入 MA 引擎。
