# 192 · 移动止损与时间止损

对照第十五万轮 AH06–AH09、AH27、AH33、AH61；衔接 [184](184-atr-stop-sizing.md)、[05](05-ashare-pitfalls.md)、[160](160-paper-live-reconciliation.md)。

## 1. 核心错误

移动止损同 K 成交；回撤%海选；缺口穿价按限价满成；无最大持仓日；当日买入当日止损卖出（破 T+1）。

## 2. 改法

移动/时间止损预注册；**收盘确认→次开**（或显式盘中规则）；穿价按开盘/涨跌停；与 ATR 一体；不改金叉开仓条件。

## 3. 本应用

止损属风控层；金叉+RSI 主路径锁定。
