# 203 · 回撤深度与持续期

对照第十六万轮 AI21–AI24、AI30、AI45、AI64、AI99；衔接 [50](50-batch6-audit-ops.md)、[161](161-strategy-retirement.md)、[185](185-vol-targeting-pitfalls.md)。

## 1. 核心错误

只看 MDD 忽略时长；恢复期不计；深度达标但长期阴跌仍上线；用回撤指标改开仓。

## 2. 改法

**深度 + 持续期** 双门禁；超时触发降仓/Kill/退役评估；与 vol 目标分层；不改金叉方向。

## 3. 本应用

回撤门禁属上线/运维；冲突以代码为准。
