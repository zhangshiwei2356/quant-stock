# 146 · 股指期货基差与股票账户边界

对照 AA30–AA35、AA45、AA56；衔接 [99](99-mega10k-audit.md)、[125](125-index-enhance-pairs.md)、[133](133-corporate-action-signals.md)。

## 1. 核心错误

贴水必反弹直接开多股票；用最终分红总额估基差；2024 中期分红后仍用旧季节；无期指权限回测期指策略；基差改个股金叉。

## 2. 对比解析

分红季常使 IH/IF 基差季节性走弱后修复，但规律随中期分红政策漂移；且属**期货账户**工具，不可与股票金叉主路径混账户。

## 3. 本应用

期现分册；权限声明；禁并个股开仓方向。
