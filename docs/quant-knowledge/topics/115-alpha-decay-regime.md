# 115 · Alpha 衰减、拥挤与政权

对照 W11–W25；衔接 [88](88-capacity-alpha-decay.md)、[46](46-dsr-pbo-validation.md)、[53](53-stress-bootstrap.md)。

## 1. 核心错误

假设 Alpha 恒定；拥挤信号炒均值收益；HMM 事后贴牛熊标签；只报全期 Sharpe 忽略最差政权（MRP）；持仓周期与半衰期错配。

## 2. 对比解析

公开研究倾向：机械因子（动量等）拥挤/衰减更快；拥挤更宜管**尾部风险**而非择时 Alpha；政权标签必须因果可知，禁止 Viterbi 全样本前视。

## 3. 改法

衰减曲线 + 滚动 IC 告警；MRP/政权压力；拥挤降仓分因子；政权只降权不改金叉方向。

## 4. 本应用

衰减/政权监控属储备门禁；公开半衰期不可外推。
