# 26 · 涨停板 / 打板策略纠错（非本应用主路径）

对照 ERRATA E37–E38、E41；**与本应用涨停拒开对立——勿混用**。

## 1. 核心统计教训（公开回测量级）

- 无差别追涨停：长期期望常**为负**  
- 隐性成本：次日**高开**抬高买入价  
- 连板低概率；强板买不进、弱板易买到（执行偏差）

## 2. 回测致命错

| 错误 | 后果 |
|------|------|
| 涨停价必成交 | 乐观幸存者 |
| 忽略一字板不可买 | 虚高 |
| 单帧封单 | 假封单噪声 |
| 固定次日收盘卖 | 低开巨亏未控 |

## 3. 若研究打板（储备）

筛：早封、封成比、板块地位、开板次数；成交用次日竞价/开盘未封死等保守规则；严格止损。  
与趋势金叉分册，共享账户风控即可。
