# 140 · 限售解禁与减持压力

对照 Z39–Z46、Z57；衔接 [96](96-event-driven-clock.md)、[115](115-alpha-decay-regime.md)、[59](59-margin-short-ashare.md)。

## 1. 核心错误

解禁日必跌并假设可空；最新解禁表回填；解禁前 N 日参数扫；牛熊一刀切；减持计划终值。

## 2. 对比解析

公开复盘常见：负向冲击多集中解禁前一段时间且幅度有限、事后回复——须 PIT 日历与分政权，禁止把事件 CAR 当保证。

## 3. 改法

公告可知日；预注册窗口；多头规避式池过滤；分政权；A 股空腿声明缺口。

## 4. 本应用

解禁/减持沙箱；不改金叉方向。
