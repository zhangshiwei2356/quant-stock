# 135 · 实施缺口（IS）分解与 TCA

对照第七万轮 Z01–Z10、Z51–Z53；衔接 [128](128-vwap-twap-execution.md)、[31](31-execution-gap-is.md)、[20](20-cost-slippage.md)。

## 1. 核心错误

只报总 IS；决策价/到达价随意或用终日中价；把延迟当成冲击；未成交当零成本；只看均值忽略尾部。

## 2. 对比解析

扩展 IS 常拆为：**延迟**（决策→到达）+ **成交/冲击**（到达→均价）+ **机会**（未成）+ **显式费用**。修复路径不同，不可混诊。

## 3. 本应用

TCA 分项属执行审计；**不**改金叉方向；无 L1/L2 须声明价差缺口。
