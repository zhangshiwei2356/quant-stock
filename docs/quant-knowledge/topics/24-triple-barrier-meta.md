# 24 · 三重障碍标签与 Meta-labeling

对照 ERRATA E33–E34、E39、E42；衔接 [18](18-ml-purged-cv.md)、[09](09-entry-exit-corrections.md)。

## 1. 固定持有期标签的问题

「T+N 收盘收益涨跌」忽略：途中止损、跳空、涨跌停不可平。  
与真实策略结果不对齐 → ML 学错目标。

## 2. 三重障碍

从信号时点向前：

1. 上障：止盈（常按波动倍数）  
2. 下障：止损  
3. 垂直障：最大持有期  

**先触达者**定标签。障碍宜随波动（如 ATR）缩放。

## 3. Meta-labeling

- 主模型：定方向（或规则金叉）  
- Meta：预测主信号是否成功 → **仓位/是否下单**，不是再学方向  

## 4. A股补丁

路径模拟加：停牌不可触达、涨跌停成交约束、T+1 今仓不可止损卖（与本应用一致时）。  
重叠事件：uniqueness 加权 + purged CV。  
元标签专深与越界纠错：[87](87-meta-labeling.md)。
