# 38 · 隔夜跳空与止损失效

对照 ERRATA E63、E70；衔接 [31](31-execution-gap-is.md)、[16](16-ashare-overnight-auction.md)、`rules` 止损跳空节。

## 1. 核心事实

止损保证**触发意图**，不保证**成交价**。开盘价已越过止损 → 市价在更差价成交，或跌停无对手。

## 2. 仓位含义

按「止损距离」算的 1% 风险，在跳空下可能变成数倍。  
**隔夜仓必须按不利跳空压力定大小**，或事件前降仓/禁止新开隔夜。

## 3. A股对照

- 本应用：触及后基准 `max(止损价, 当根最低)` 再滑点——低开按止损价偏**乐观**  
- 跌停：卖失败累计后强平路径  
- T+1：今仓不可止损卖，跳空风险更集中在老仓可卖部分  

研发：压力测试「开盘低开 X%」净权益；财报日历接入。  
止损形态（固定 ATR / trail / 结构）对比：[60-stop-placement.md](60-stop-placement.md)。
