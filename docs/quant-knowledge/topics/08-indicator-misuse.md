# 08 · 技术指标误用对照（研发储备）

对照阅读：[ERRATA](../errata/ERRATA.md) E01–E05、E11、E13。

## 1. 均线交叉

| 做法 | 风险 | 改进 |
|------|------|------|
| 无过滤金叉 | 震荡反复止损 | 大周期方向 + ADX + 量 |
| 周期与持仓不匹配 | 信号过密/过稀 | 日线波段常用 5/20 或 20/50 类 |
| 混用 EMA/SMA 不说明 | 不可复现 | 文档写死类型与周期 |

**SMA vs EMA**：短线偏 EMA；确认偏 SMA；可组合「慢均线定方向、快均线择时」。

## 2. RSI

- **错误**：70/30 机械反转。  
- **正确**：震荡市均值回归工具；趋势市作动能确认或回撤入场区。  
- Wilder 平滑使 RSI 具有「粘性」，可长期极端。

## 3. MACD / 背离

- 背离假阳性高（急涨后减速、横盘向零轴）。  
- 须价格结构确认；不作唯一平仓理由。

## 4. ADX

- 只量强度不量方向；需 +DI/−DI 或均线方向配合。  
- ADX\<20–25：趋势策略宜暂停或切换回归。

## 5. 布林带与突破

- Squeeze≠方向；缩量假突破多。  
- 收盘确认 + 放量 + ADX 抬升。

## 6. 成交量

- 「放量」需相对均量；绝对量跨市值不可比。  
- 无量涨停/跌停另议流动性与可成交性。  

## 7. 多指标堆叠

同源震荡指标同时看多 ≠ 独立证据。正交集成见 [55-signal-ensemble.md](55-signal-ensemble.md)。
