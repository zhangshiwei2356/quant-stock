# 79 · 分析师盈利修正与一致预期

对照 ERRATA E151–E152、E162；衔接 [75](75-pead-earnings-drift.md)、[03](03-stock-selection.md)、[52](52-earnings-quality-fraud.md)。

## 1. 时钟

每条预测至少：`analyst_id`、`forecast_date`、`effective_from`（可知日）。  
一致预期须 **as-of** 聚合，禁止用最终库回填。

## 2. 常见错误

- 补录/修订后的「历史一致预期」（E151）  
- 覆盖家数用今日终值（E162）  
- 上调直接加金叉分（E152）  

## 3. 用法

修正漂移 / 超预期作**事件池或过滤**；公告后窗口可与 PEAD 协同，但分册。  
公开研报超额**不可外推**为本系统绩效。

## 4. 本应用

主路径技术金叉；分析师因子属基本面沙箱，须 PIT + 显式开关。
