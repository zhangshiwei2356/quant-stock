# 04 · 怎么计算买入 / 卖出点

把「信号」拆成：**触发条件 → 过滤条件 → 成交规则 → 出场规则**。

## 1. 均线金叉 / 死叉（趋势入场）

记 \(MA_n(t)\) 为到 \(t\) 为止 \(n\) 根收盘价简单平均。

**金叉（买入候选）**（与本应用 docs/ma 一致的逻辑）：

\[
MA_5(t-1) \le MA_{20}(t-1)\ \wedge\ MA_5(t) > MA_{20}(t)
\]

**死叉（卖出候选）**：

\[
\neg(MA_5(t-1) < MA_{20}(t-1))\ \wedge\ MA_5(t) < MA_{20}(t)
\]

可选加强：

- \(MA_{60}\) 上行过滤（趋势环境）  
- 收盘价在长期均线上方（更严）  
- ADX > 阈值（如 18–25）确认趋势强度  

## 2. RSI 过滤（避免极端区追涨杀跌）

RSI(14) 常见用法（**勿读成「70 必卖 / 30 必买」**，见 [09](09-entry-exit-corrections.md) / [ERRATA E01](../errata/ERRATA.md)）：

- 买入侧（趋势策略）：避免 RSI 已处极端追高区（本应用示例：金叉时要求 RSI\<60）  
- 趋势市：RSI 高位可表示动能强；回归式超卖抄底只适用于震荡 regime  
- 卖出侧：避免在无结构确认时仅因「超买」清仓  

具体上下界应网格+稳健性验证；**先判趋势/震荡再选阈值**。

## 3. ATR 止损 / 移动止盈（波动自适应）

真实波幅：

\[
TR_t = \max(H_t-L_t,\ |H_t-C_{t-1}|,\ |L_t-C_{t-1}|)
\]

\(ATR_n\) 为 TR 的 \(n\) 期平均（常用 14）。

**初始止损（多头示例）**：

\[
Stop_0 = Entry - k \cdot ATR
\]

常见 \(k \in [1.5, 3.0]\)。

**移动止损（只升不降）**：

\[
Stop_t = \max(Stop_{t-1},\ Close_t - k \cdot ATR_t)
\]

**浮盈收紧**（开源示例思路）：当浮盈 > \(m\cdot ATR\) 时，把 \(k\) 从宽松改为更紧，加快锁利。

**风险预算仓位**（单笔风险约账户的 \(r\)）：

\[
Shares \approx \frac{Equity \times r}{k \cdot ATR}\quad\text{再向下取整到 100 股}
\]

## 4. 成交时点（防未来函数）

| 周期 | 常见可执行规则 |
|------|----------------|
| 日 K | 信号日收盘确认 → 下一交易日开盘成交 |
| 分钟 | 信号后延迟到可交易分钟（如次日 ≥09:45） |

回测若用「当日收盘价既算信号又成交」，会系统性高估。

## 5. 完整「买」检查清单（实务）

1. 标的在目标池 / 通过硬过滤  
2. 金叉（或你的主信号）成立  
3. RSI/ADX/放量等过滤通过  
4. 非涨停（或可成交）  
5. 账户未熔断；单票与总仓上限允许  
6. 按风险预算算股数 ≥100  
7. 按成交规则挂到下一可成交时点  

## 6. 完整「卖」检查清单

1. 死叉 / 止损触发 / 移动止盈触发 / 强制风控  
2. T+1：仅可卖「非当日买入」批次  
3. 非跌停封死（否则可能卖不出）  
4. 部分卖出后是否保留挂单清仓
