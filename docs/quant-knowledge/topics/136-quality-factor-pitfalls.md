# 136 · 质量因子与应计陷阱

对照 Z11–Z16、Z48、Z54；衔接 [96](96-event-driven-clock.md)、[114](114-multifactor-selection-pitfalls.md)、[98](98-factor-neutralization-pit.md)。

## 1. 核心错误

最新财报质量前视；应计用更正终值；全样本标准化；未行业中性；高质量静默改金叉。

## 2. 改法

披露/公告 PIT；截面 rank；as-of 中性；滚动 IC；池过滤式沙箱。

## 3. 本应用

质量因子不替代 MA5/MA20 金叉；公开海外质量溢价不可外推。
