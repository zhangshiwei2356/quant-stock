# 39 · 再平衡：日历 vs 带宽

对照 ERRATA E64–E65、E72；衔接 [20](20-execution-cost-impact.md)、[25](25-portfolio-opt-risk-model.md)。

## 1. 两类问题

| | 信号调仓（本应用主路径） | 权重再平衡 |
|--|--------------------------|------------|
| 触发 | 金叉/死叉/止损 | 权重漂移出带 |
| 目标 | 有无仓/加减仓 | 贴近目标权重 |
| 频率 | 事件驱动 | 日历或带宽 |

勿把每日强制再平衡当作「让金叉更准」。

## 2. 纠错

- 越勤再平衡 ≠ 更好：月/季与日差异常小于成本差（配置类研究常见结论）  
- **带宽/无交易带**通常优于纯日历猛调  
- 破带可调到**内沿**而非一次打回中心，降换手  
- 监控可以密，交易可以稀  

## 3. 研发

多因子增强组合：带宽 + 冲击预算；与金叉引擎分离配置。
