# 167 · 流动性政权检测

对照第十一万轮 AD24–AD28、AD43、AD49、AD73；衔接 [56](56-participation-sizing.md)、[115](115-alpha-decay-regime.md)、[157](157-capacity-aum-scaling.md)。

## 1. 核心错误

无政权标签常满仓；ADV 骤降仍满额；降仓口头无硬顶；低流动政权改开多；公开换手阈值外推。

## 2. 改法

滚动 ADV/冲击代理打政权标签；断崖触发降仓+参与率硬顶；标签用例验收；政权只滤/降，不开仓。

## 3. 本应用

政权层挂在风控/仓位，不改金叉主路径。
