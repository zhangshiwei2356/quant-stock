# 152 · 回撤买入 vs 突破买入

对照 AB17–AB22、AB36–AB37、AB43–AB44；衔接 [143](143-squeeze-breakout-pitfalls.md)、[142](142-indicator-confirm-pitfalls.md)、[38](38-gap-overnight-stop.md)。

## 1. 核心错误

任意回撤必买（接飞刀）；回撤%海选；突破必续；两范式混用无开关；同 K 触及/破位成交；涨停当可买突破。

## 2. 改法

趋势过滤+ATR 缓冲；预注册参数；分册显式开关；收盘确认→次开；板状态；止损优先于回撤加仓。

## 3. 本应用

金叉确认后的**择时层**；不得改写金叉方向；对齐金字塔加仓。
