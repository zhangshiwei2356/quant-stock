# 31 · 回测–纸面–实盘落差与 IS

对照 ERRATA E49–E51、E57–E59；衔接 [20](20-execution-cost-impact.md)、[11](11-validation-corrections.md)。

## 1. 三层验证

| 层 | 能验 | 不能验 |
|----|------|--------|
| 回测 | 规则逻辑、粗成本 | 真实冲击、延迟 |
| 纸面 | OMS/时钟/拒单机械 | **自己推价** |
| 实盘 | 真冲击与部分成交 | — |

## 2. Implementation Shortfall（决策→成交）

相对**决策时到达价**：冲击 + 价差 + 延迟 + **未成交机会成本**。  
勿只用「是否优于 VWAP」验收执行。

## 3. 落差诊断顺序

1. 同区间同信号：回测 vs 纸面 vs 实盘  
2. 分解 IS 最大项  
3. 未改信号前先修成交假设  
4. 样本够（数十笔级）再判策略死活  

## 4. 本应用

已有分级滑点、冲击上限、挂单重试/过期。研发应加压测 fill rate&lt;1 与冲击×2。  

诊断分工：执行落差用本文 IS；隔夜跳空用 [38](38-gap-risk-stops.md)；仓位相关用 [37](37-portfolio-heat.md)——三轨日志可同步记录 Heat 状态。算法切片与「赢 VWAP≠好执行」见 [67](67-vwap-twap-execution.md)。
