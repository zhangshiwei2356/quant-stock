# 59 · 融资融券约束与因子

对照 ERRATA E108–E110；衔接 [21](21-vol-targeting-risk-parity.md)、[52](52-earnings-quality-fraud.md)。

## 1. A股特征

长期「融资相对活跃、融券受限」：券源、标的池、费率使**自由卖空回测不可信**。

## 2. 用法边界

| 用途 | 注意 |
|------|------|
| 融券余额等因子 | 含费后分层；高换手敏感 |
| 融资加仓 | 维持担保比例硬门控 + 强平路径 |
| 变相 T+0 | 须底仓/券源；非主金叉路径 |
| 市场中性 | 空腿工具可得性决定可行性 |

## 3. 本应用

默认现金多头 + T+1。研发两融：独立账户假设；禁止把「任意卖空」写进主回测。
