# 68 · 突破入场 vs 回踩入场

对照 ERRATA E128–E129、E134；衔接 [09](09-entry-exit-corrections.md)、[47](47-mtf-confirmation.md)、金叉（均线交叉偏「结构确认」非影线突破）。

## 1. 对比

| | 突破 | 回踩 |
|--|------|------|
| 优点 | 跟上强趋势 | 止损更紧、RR 常更好 |
| 缺点 | 假突破多、止损宽 | 强趋势不回给则踏空 |

## 2. 量化注意

- 影线/盘中破 ≠ 收盘确认  
- 须预注册：何种动能用突破、何种等回踩  
- 与金叉混用须显式开关并计试验次数 N  

## 3. 本应用

主路径是 **MA 金叉 + 过滤**（收盘确认），不是影线突破。若加突破腿：分册或开关，禁止静默堆条件。
