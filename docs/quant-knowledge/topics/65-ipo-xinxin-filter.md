# 65 · 次新 / IPO 池过滤

对照 ERRATA E121–E122；衔接 [03](03-stock-selection.md)、[05](05-ashare-pitfalls.md)、[44](44-universe-pit-survivorship.md)。

## 1. 为何虚高

上市初期连续涨停、薄量、规则特殊；回测易「完美买入」躺赚，实盘买不到。财务与均线窗口也未成熟。

## 2. 做法

- 硬过滤：上市满 **N** 日（常见 6–12 月或 120–252 交易日）  
- 涨停拒开；参与率/冲击另限  
- 板块规则差异（主板/创业/科创涨跌幅）勿混用同一撮合假设  

## 3. 本应用

`OpenFilter` 含次新/涨跌停等方向；知识库要求回测宇宙显式上市日门槛，并与涨停拒开一致。
