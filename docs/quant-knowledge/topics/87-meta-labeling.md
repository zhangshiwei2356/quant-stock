# 87 · 元标签（Meta-Labeling）

对照 ERRATA E168–E169、E178；衔接 [24](24-triple-barrier-meta.md)、[46](46-dsr-pbo-validation.md)、[76](76-kelly-fractional-sizing.md)。

## 1. 分工

| 层 | 职责 |
|----|------|
| 主模型 | **方向**（如金叉 / 事件多头） |
| 次模型 | **是否交易 / 仓位大小**（滤假阳） |

次模不应改写多空方向（E168）。

## 2. 常见错误

- 次模学方向（E168）  
- 标签/特征未 purge（E169）  
- 概率直接当仓位比例无硬顶（E178）  

## 3. 改法

高召回主信号 + 次模提精确；purged/CPCV；仓位映射到 ATR/分数 Kelly + 单票上限。

## 4. 本应用

主路径仍为规则金叉；元标签属 ML 滤网沙箱，须显式开关与验证门禁。
