# 123 · 盈余公告后漂移（PEAD）

对照 X21–X28、X67；衔接 [96](96-event-driven-clock.md)、[124](124-liquidity-adv-filter.md)、[20](20-cost-slippage.md)。

## 1. 核心错误

SUE 纸面多空当可实施；忽略非流动股成本吃光超额；公告前埋伏；预期终值回填；美股结论套 A 股。

## 2. 对比解析

公开研究常见结论：PEAD 超额多集中于非流动股；交易成本可消耗大部分纸面利润——须 ADV/冲击同测。

## 3. 本应用

事件沙箱；公告后可知时点；A 股空腿受限；禁并金叉。
