# 09 · 买卖点计算纠错版

在 [04-entry-exit.md](04-entry-exit.md) 基础上，补「错法 → 改法」。

## 1. 入场公式（趋势金叉路径）

保留：

\[
MA_5(t-1)\le MA_{20}(t-1)\ \wedge\ MA_5(t)>MA_{20}(t)
\]

**曾隐含的错误**：金叉当日收盘价既信号又成交 → 未来函数。  
**改法**：信号收盘确认 → 下一可成交时点。

**过滤层纠错**：

| 旧直觉 | 问题 | 改法 |
|--------|------|------|
| RSI>70 禁止一切多 | 趋势强势时拒掉优质趋势 | 用「避免追极端」（如 RSI\<60）或趋势内回撤区 |
| 无 ADX | 震荡金叉亏损堆叠 | ADX≥阈值才允许趋势入场 |
| 影线突破即买 | 假突破 | 收盘突破 + 量能 |

## 2. 出场公式纠错

| 类型 | 错法 | 改法 |
|------|------|------|
| 死叉 | 与止损同日冲突未定义优先级 | 显式优先级（本应用：先止损/trail） |
| 固定 % 止损 | 忽视个股波动 | \(k\cdot ATR\) |
| 过紧 trail | 利润回吐前被扫 | 波段约 1.5–2.5×ATR；事件前降仓 |
| 背离提前清仓 | 过早下车 | 结构破位或规则止损为准 |

## 3. 仓位与止损耦合

分母必须等于**实际执行止损距离**（含夹逼后更紧者）。  
否则「风险 1%」名不副实。

## 4. A股成交约束写入买卖点

买入点成立但仍可能不成交：涨停、静默、熔断、不足一手。  
卖出点成立仍可能不成交：跌停、T+1 今仓。  
**研发启示**：信号引擎与成交引擎必须分离建模。  

## 5. 多周期确认

低周期金叉须服从高周期方向，否则鞭打为主。  
专深：[47-mtf-confirmation.md](47-mtf-confirmation.md)。
