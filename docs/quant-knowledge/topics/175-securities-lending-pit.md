# 175 · 融券标的 PIT 与多头边界

对照第十二万轮 AE33–AE36、AE56、AE97；衔接 [103](103-crossborder-etf-boundary.md)、[109](109-program-trading-reg-detail.md)、[29](29-paradigm-matrix.md)。

## 1. 核心错误

融券池无 as-of；假设永久可空；融券余额当多头信号；无权限融券腿混入股票多头路径。

## 2. 改法

融券标的 **日切 PIT**（若做空/对冲）；本应用默认 **多头边界声明**：无融券权限则禁止空头腿；余额类信号分册且只滤不开。

## 3. 本应用

主路径为股票多头金叉；融券主题仅作边界与沙箱储备，不改开仓方向。
