# 149 · 概念题材轮动陷阱

对照第九万轮 AB01–AB06、AB33、AB40；衔接 [115](115-alpha-decay-regime.md)、[117](117-industry-rotation-pitfalls.md)、[95](95-limit-board-sentiment.md)。

## 1. 核心错误

热点当周追次周；热度打满仍追；最新题材成分回测；舆情热度终包；单题材堆仓；日频轮动费后为负。

## 2. 对比解析

公开研究常见：热度当周涨幅大、次周优势易消失；热度打满次周或回落；政策与主题**正向共振**优于纯追热——仍须 PIT，公开超额不可外推。

## 3. 本应用

题材池沙箱；拥挤/Heat 取严；**不**改金叉方向。
