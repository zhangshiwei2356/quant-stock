# 32 · 订单簿 / L2 特征纠错

对照 ERRATA E52–E53；衔接 [16](16-ashare-overnight-auction.md)。

## 1. OBI 能做什么

盘口不平衡对**极短**期限有信息；衰减快。  
相关未必可因果交易；幌骗、冰山、碎片化破坏信号。

## 2. 常见错

| 错误 | 改法 |
|------|------|
| OBI 持有数日 | 持有期匹配衰减 |
| 全样本标准化 | 滚动因果 |
| 到达时戳排序 | 交易所事件序 |
| 原始簿状态硬训深度网 | 常不如平稳 order flow 特征 |
| 无延迟模型 | 仿真加延迟否则虚高 |

## 3. 与本应用

主路径日/分钟 K + 技术池，**非** L2。L2 仅独立高频沙箱；勿并入金叉引擎。  
VPIN/OFI 误用与实现要点：[83](83-orderflow-vpin.md)。
