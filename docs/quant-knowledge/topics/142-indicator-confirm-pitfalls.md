# 142 · 多指标确认陷阱（RSI/MACD）

对照第八万轮 AA01–AA10、AA41、AA49–AA52；衔接 [07](07-map-to-this-app.md)、[122](122-samebar-gap-breakout.md)、[46](46-dsr-pbo-validation.md)。

## 1. 核心错误

同质指标叠滤导致零成交；趋势中 RSI 超买必卖；同 K 确认成交；MACD 盘中偷价；确认层静默改金叉方向；过滤后 N 过小当显著。

## 2. 对比解析

互补组合应回答不同问题（趋势/动量/波动），而非同一动量问五遍。本应用既有 **RSI&lt;60** 滤镜：属确认层，**不得**反向改写 MA5/MA20 金叉方向。

## 3. 改法

一类一指标；收盘确认→次开；预注册阈值；最小成交笔数/计 N；契约测试对齐代码。

## 4. 本应用

金叉为主、RSI 为滤；冲突以 `rules`/代码为准。
