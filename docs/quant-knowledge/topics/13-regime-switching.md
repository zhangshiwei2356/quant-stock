# 13 · Regime：趋势 vs 均值回归切换

对照 ERRATA E13。

## 1. 为什么要切换

同一指标在不同 regime 含义相反：

| Regime | RSI 高位 | 金叉 | 布林触上轨 |
|--------|----------|------|------------|
| 趋势 | 动能强 | 顺势 | 可能延续 |
| 震荡 | 超买 | 易假 | 常回归 |

## 2. 实用开关（示例）

```
if ADX < 20:  禁用趋势入场；可启用回归（需独立回测）
elif ADX >= 25 and rising:  允许趋势突破/金叉
else:  谨慎或观望
```

方向仍需均线/价格结构，ADX 不管多空。

## 3. 研发注意

- 两套规则参数分别优化，禁止「一套参数打天下」。  
- 切换本身也是参数 → 计入过拟合预算。  
- 本应用主路径是趋势金叉；回归策略属另册储备。
