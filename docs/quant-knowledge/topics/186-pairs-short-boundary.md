# 186 · 配对交易与空头边界

对照第十四万轮 AG10–AG13、AG27、AG43、AG45、AG62；衔接 [175](175-securities-lending-pit.md)、[125](125-index-enhance-pairs.md)、[29](29-paradigm-matrix.md)。

## 1. 核心错误

相关当协整；价差发散不止损；无融券权限硬空；融券池无 PIT；单腿超限；公开配对 IR 外推。

## 2. 改法

协整/行业约束预注册；发散/时间止损；**无空头权限则禁配对空腿或仅多头相对强弱分册**；融券 as-of；不并金叉主路径。

## 3. 本应用

默认股票多头金叉；配对属另册沙箱。
