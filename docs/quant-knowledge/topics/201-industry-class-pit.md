# 201 · 行业分类 PIT

对照第十六万轮 AI13–AI16、AI28、AI35、AI37、AI62；衔接 [114](114-multifactor-selection-pitfalls.md)、[104](104-feature-store-point-in-time.md)、[159](159-benchmark-selection-pitfalls.md)。

## 1. 核心错误

用现申万/中信回测历史；重分类前视；行业中性用错篮子；残差归因失真；行业轮动分改金叉。

## 2. 改法

reclass **as-of 日志**；中性化/归因用当时行业；多源行业对账；行业主题分册只滤不开。

## 3. 本应用

行业中性属选股沙箱；不并金叉主路径。
