# 55 · 信号集成与正交性

对照 ERRATA E99–E101；衔接 [47](47-mtf-confirmation.md)、[24](24-triple-barrier-meta.md)、[46](46-dsr-pbo-validation.md)。

## 1. 假分散

RSI + KDJ + CCI 同时看多 ≠ 三个独立证据，多为**同一价格向量**的相关变换 → 有效自由度≈1。

## 2. 正交轴（示例）

异族信号才有集成意义，例如：

- 价格趋势（MA 金叉）  
- 量能/流动性  
- 事件/持仓约束（解禁窗、财报窗）  
- （可选）低相关基本面过滤  

在**验证窗**上算秩相关；相关过高则不算新票。

## 3. 合成方式

优先：**多数决 / 等权 / 一票否决滤网**。  
避免：大规模 IS 权重网格（试次爆炸）。  
成员须**各自**过基础期望与成本门禁，再进入投票。

## 4. 与 meta-label

Meta-label 是「主信号是否下单」的二分类层，不是把十个相关指标加权。二者可叠，但计 N。

## 5. 本应用

已有金叉 + RSI/ATR 滤，接近「主信号 + 滤网」。研发勿再堆同源震荡指标；可加正交事件滤（解禁/Heat）并做正交性检查。
