# 128 · VWAP/TWAP 执行与买卖落地

对照第六万轮 Y01–Y10、Y51–Y56；衔接 [31](31-execution-gap-is.md)、[56](56-participation-sizing.md)、[121](121-call-auction-signals.md)。

## 1. 核心错误

用终日 VWAP 当成交价；均匀 TWAP 无视开盘/尾盘 U 型；到达后用终值 VWAP 评测（前视基准）；涨跌停仍灌单；执行进度改信号方向。

## 2. 对比解析

订单拆分基准会制造可预测盘中价格压力并降低流动性；评测须用**到达时**可得的 VWAP/轨迹，而非收盘后复盘终值。

## 3. 本应用

执行算法 ≠ 开仓信号；切片对齐整手/参与率/限速；金叉确认后再切片。
