# 130 · 波动率目标仓位

对照 Y21–Y28、Y58、Y67；衔接 [76](76-kelly-fractional-sizing.md)、[50](50-batch6-audit-ops.md)、[07](07-map-to-this-app.md)。

## 1. 核心错误

用未来实现波动定仓；vol target 软化熔断；个股目标当组合；低波加杠杆破单票/总仓顶；与 ATR 止损优先级不明。

## 2. 改法

滞后波动 PIT；硬门控覆盖 vol；组合波动 + Heat；预注册估计窗；文档化与 ATR 取严规则。

## 3. 本应用

vol 目标属仓位层储备；不得突破账面≤80%、单票≤30%。
