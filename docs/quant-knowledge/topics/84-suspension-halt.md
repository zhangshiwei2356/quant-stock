# 84 · 停牌、复牌与交易状态

对照 ERRATA E157–E158、E164；衔接 [05](05-ashare-pitfalls.md)、[44](44-universe-pit-survivorship.md)、[72](72-opening-auction.md)、[38](38-gap-risk-stops.md)。

## 1. 非法撮合

停牌日流动性为零。用昨收 ffill 后「成交」= 虚假 Alpha（E157）。

## 2. 复牌

复牌首日常伴随集合竞价特殊规则与跳空；按普通连续/金叉撮合易错（E158）。

## 3. 截面污染

熔断/大面积停牌日仍对「全市场」做 Z-score，宇宙已变（E164）。

## 4. 改法

交易状态字典（可交易/停牌/熔断）；信号前硬校验；持仓停牌如实占用资金；复牌事件降权或拒新开。

## 5. 本应用

对照涨跌停拒成与宇宙过滤；知识库要求停牌不可撮合写入验收用例。
