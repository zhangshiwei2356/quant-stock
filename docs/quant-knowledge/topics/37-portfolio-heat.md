# 37 · 组合热度（Portfolio Heat）与相关

对照 ERRATA E61–E62、E69、E71、E74；衔接 [12](12-risk-corrections.md)、[07](07-map-to-this-app.md)。

## 1. 定义

**Heat** ≈ 若所有止损同时触发，相对**当前权益**的总亏损占比。  
单票 1% × N **不等于**组合 Hot，除非互不相关。

## 2. 常见错

| 错误 | 改法 |
|------|------|
| 数票当分散 | 按板块/主题聚类，相关仓加权 |
| 只开仓时算一次 | 动态更新 |
| 用初始本金 | 用当前权益 |
| 平静期相关估压力 | 压力相关→1 情景 |
| 有信号就开 | Heat/板块近限 → 拒开或缩量 |

## 3. 经验量级（仅参考）

文献常见总 Heat 上限约数个百分到十余百分；相关簇更严。须按账户与策略自定。
