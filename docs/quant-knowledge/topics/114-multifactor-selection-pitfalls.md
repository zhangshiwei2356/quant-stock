# 114 · 多因子选股陷阱

对照第四万轮 W01–W10、W46–W49、W81–W82；衔接 [98](98-factor-neutralization-pit.md)、[46](46-dsr-pbo-validation.md)、[104](104-feature-store-point-in-time.md)。

## 1. 核心错误

全样本 Z 标准化；因子方向未统一；相关因子叠权；IC 只报全期；权重海选无计 N；换手成本忽略。

## 2. 改法

截面内排名（或滚动历史窗标准化）+ 信号滞后；行业/市值 as-of 中性；滚动 IC/ICIR；等权起步；成本同测；预注册因子集。

## 3. 本应用

多因子池可作**选股沙箱**，**不**静默替代 MA5/MA20 金叉开仓方向。非投资建议。
