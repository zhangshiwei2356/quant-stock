# 76 · Kelly 定仓与分数 Kelly

对照 ERRATA E144；衔接 [12](12-risk-corrections.md)、[37](37-portfolio-heat.md)、[56](56-participation-sizing.md)。

## 1. 公式意图

Kelly 最大化长期几何增长率，**不**最小化回撤或心理痛苦。  
输入为胜率 p、盈亏比 b（或连续情形下的均值/方差）；皆为**估计值**。

## 2. 常见错误

- 回测胜率喂**全 Kelly**（E144）  
- 多腿相关仓各自 Kelly 再相加  
- 未扣滑点/税费即算 edge  

过赌惩罚极非对称：约 2× 真 Kelly 时期望增长可归零。

## 3. 实务改法

- **½–¼ Kelly** 为常见上界；新策略/政权切换更保守  
- 与 ATR 风险、单票上限、Heat、ADV 参与率取**更严者**  
- 样本外估计；至少数十笔级才谈稳定 p、b  

## 4. 本应用

现行偏 ATR/账户比例与硬顶（单票/总仓）；Kelly 仅作理论上界对照，**禁止**用样本内全 Kelly 覆盖风控。
