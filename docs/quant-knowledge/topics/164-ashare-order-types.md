# 164 · A股订单类型陷阱

对照第十一万轮 AD07–AD12、AD16；衔接 [05](05-ashare-pitfalls.md)、[20](20-execution-cost-impact.md)、[128](128-vwap-twap-execution.md)。

## 1. 核心错误

照搬美股市价；最优五档当无限深度；无保护价止损狂滑；加价追涨停无视拒单；IOC/FOK 语义混用。

## 2. 改法

默认**限价+保护价**；五档/ADV 深度上限；涨跌停拒单进回测；订单假设预注册；执行层与信号层分离。

## 3. 本应用

订单类型属执行沙箱；不得静默改金叉开仓方向；RSI 仍只滤不开。
