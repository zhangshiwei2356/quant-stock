# 44 · 时点宇宙与幸存者（深化）

对照 ERRATA E76–E78；扩展 [05](05-ashare-pitfalls.md) §1；衔接 [11](11-validation-corrections.md)。

## 1. 两种偏差别混

| | 前视 | 幸存者 |
|--|------|--------|
| 含义 | 用了当时不可知信息 | 样本丢掉「已消失」路径 |
| 典型 | 今天成分倒灌历史 | 只留仍上市标的 |
| 同现 | 当前名单回填且无退出样本 | 高估最常见 |

## 2. 成分三日期契约

每条成员资格至少：`announced_at` / `effective_from` / `effective_to`。  
公告后、生效前调仓须**显式**写成策略规则，不可把生效日当知晓日。

## 3. 退市收益

忽略退市收益会系统性抬高宇宙收益。缺失时按原因保守插补（破产近零、并购用对价），并报告敏感性。

## 4. 借壳与代码变更

同代码 ≠ 同公司。须永久 ID + 事件表；财务/行业按 PIT 快照，禁止重组后数据向前渗透。

## 5. 本应用

目标池/扫描应坚持 as-of；知识库不改代码。无历史成分时：**缩短区间**或标注「当前成分历史特征研究」，禁止写成可实施回测。
