# 163 · 可复现研究

对照第十一万轮 AD01–AD06、AD41、AD57、AD70；衔接 [46](46-dsr-pbo-validation.md)、[160](160-paper-live-reconciliation.md)、[15](15-cross-link-map.md)。

## 1. 核心错误

无配置哈希/种子；notebook 临时改参；特征泄漏未登记；环境漂移导致对照失效；把研究分静默并入金叉。

## 2. 改法

实验预注册 + **配置哈希** + 固定种子；特征泄漏台账（PIT）；事件/成交日志可对照；样本外计 N；研究输出只进沙箱闸门。

## 3. 本应用

复现属研发门禁，不改 MA5/MA20 金叉主路径；冲突以 `rules.html`/代码为准。
