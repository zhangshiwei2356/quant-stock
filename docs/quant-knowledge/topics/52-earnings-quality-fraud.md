# 52 · 盈余质量与造假红旗（选股减法）

对照 ERRATA E93–E94、E104；衔接 [49](49-value-quality-trap.md)、[44](44-universe-pit-survivorship.md)。

## 1. 造假 vs 盈余管理

量化评分多捕捉**相对风险**（应计偏高、利润与现金流背离、存贷双高等），**不能定罪**。业绩爆发期指标也会异动。

## 2. 实用减法

| 线索 | 用法 |
|------|------|
| 高应计 / 低 CFO 质量 | 降权或剔除；行业内分位 |
| 应收/存货/毛利率异动 | 与同行比较，非绝对阈值 |
| M-Score 等复合分 | 高分回避，非做空信号（融券约束下） |

应计持续性通常弱于现金流 → 「假成长」风险。

## 3. 错误

全市场统一阈值；把评分当 Alpha 多头；无 PIT 用重述后财报。

## 4. 本应用

技术池主路径可不依赖财务。若加基本面腿：**质量/红旗作过滤**，与估值交叉，禁止裸利润成长排序并入金叉。  
价值交叉见 [49](49-value-quality-trap.md)。
