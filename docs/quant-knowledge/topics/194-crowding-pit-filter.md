# 194 · 拥挤度 PIT 过滤

对照第十五万轮 AH14–AH17、AH29、AH37、AH91；衔接 [102](102-chip-shareholder-count.md)、[157](157-capacity-aum-scaling.md)、[156](156-signal-ensemble-gating.md)。

## 1. 核心错误

现截面滤历史；持仓/筹码披露前视；拥挤当开仓；拥挤票仍高参与率；阈值海选。

## 2. 改法

披露 **as-of**；拥挤只滤/降仓不开；与参与率硬顶联动；预注册定义；极端拥挤可 Kill。

## 3. 本应用

拥挤属滤镜/仓位层；不改金叉方向。
