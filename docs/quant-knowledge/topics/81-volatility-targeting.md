# 81 · 波动率目标仓位（Vol Targeting）

对照 ERRATA E154、E159；衔接 [12](12-risk-corrections.md)、[76](76-kelly-fractional-sizing.md)、[77](77-correlation-spike.md)。

## 1. 意图

按预测波动缩放暴露，使组合实现波动更接近目标；风险资产上常伴随「类动量」效应（跌→波升→减仓）。

## 2. 常见错误

- 低波无限加杠杆（E154）  
- 用 vol 缩放**替代**回撤熔断（E159）  
- 估计窗过短 → 鞭梢式调仓  

## 3. 改法

目标波动 × **杠杆/总仓硬顶** × Heat；与 ATR 单票风险取严。  
亲周期性：危机去杠杆可能助跌——资本规划须压力情景。

## 4. 本应用

已有 ATR/回撤系数/硬顶；vol targeting 是可选总暴露缩放，**不**关闭熔断。
