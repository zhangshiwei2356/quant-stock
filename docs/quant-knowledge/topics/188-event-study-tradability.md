# 188 · 事件研究可交易性

对照第十四万轮 AG18–AG21、AG29、AG38、AG70；衔接 [174](174-earnings-calendar-pit.md)、[150](150-policy-event-trading.md)、[123](123-pead-earnings-drift.md)。

## 1. 核心错误

事件窗前视；事后挑事件；CAR 当可交易 alpha；公告前交易；同 K 成交；幸存者事件样本。

## 2. 改法

公告/可知 **as-of**；事件清单预注册；落地检 T+1/涨跌停；CAR≠下单信号；分册沙箱；配置哈希可复现。

## 3. 本应用

事件主题不并金叉；公开 CAR 不可外推。
