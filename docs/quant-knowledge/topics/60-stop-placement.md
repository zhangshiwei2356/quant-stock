# 60 · 止损形态：ATR / Chandelier / 结构

对照 ERRATA E111–E112、E119；衔接 [09](09-entry-exit-corrections.md)、[38](38-gap-risk-stops.md)、本应用 ATR 规则。

## 1. 三类对比

| 类型 | 锚点 | 易错 |
|------|------|------|
| 固定 ATR 止损 | 入场价 − k×ATR | 波动扩张后过紧 |
| Chandelier / ATR trail | 持仓最高 − m×ATR | 震荡千刀万剐；非必然优于固定 |
| 结构止损 | 摆动低点下方 | 判定主观；须规则化 |

## 2. 研究提示

- trail ≠ 免费午餐；分 regime（趋势/震荡）对比  
- 倍数随周期/品种标定，勿全球套 3×ATR(22)  
- 与跳空：触发≠成交（[38](38-gap-risk-stops.md)）  
- 多规则并存须写清优先级（更紧者 / 分阶段）

## 3. 本应用

默认：止损约 2×ATR（夹权益约束）、trail 约 1.5×ATR、只上移。  
研发改倍数属参数试验 → 计 N + WFA；勿与打板止损逻辑混用。
