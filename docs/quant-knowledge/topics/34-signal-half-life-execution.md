# 34 · 信号半衰期 × 执行可行性

对照 ERRATA E59；衔接 [23](23-momentum-reversal-rotation.md)、[31](31-execution-gap-is.md)。

## 矩阵（研发用）

| 信号衰减 | 可承受延迟/冲击 | 典型 |
|----------|-----------------|------|
| 秒～分钟 | 极低 | L2/OBI |
| 日内小时 | 低 | 竞价/打板 |
| 数日 | 中 | 金叉/短动量 |
| 数周～月 | 较高 | 多因子调仓 |

**规则**：半衰期 &lt; 2×（决策到成交时间）→ 策略在真实执行下期望常被吃光。  
本应用金叉偏日频+次日开盘，要求信号在日尺度仍有边。
