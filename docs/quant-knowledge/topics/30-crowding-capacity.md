# 30 · 因子拥挤与策略容量

对照 ERRATA E46–E48；衔接 [10](10-factor-selection-corrections.md)、[20](20-execution-cost-impact.md)。

## 1. 拥挤是什么

资金同向追逐同一因子 → 收益不稳、回撤变胖，极端时拥挤崩溃。  
失效原因要拆：**拥挤** vs **样本内过拟合**（见发表后衰减文献）。

## 2. 监测维度（示例）

| 维 | 例子 |
|----|------|
| 估值/价差 | 多空估值价差极端 |
| 相关 | 因子收益配对相关升高 |
| 波动 | 多空相对波动异常 |
| 持仓 | 机构集中度、暴露市值占比 |
| 交易 | 相对换手、冲击扩大 |

**错法**：单指标、或把拥挤当稳定反向 Alpha。  
**改法**：复合指标 + 分位**降风险预算**（尾部预警思维）。

## 3. 容量

勿线性外推「成交额×5%」。做规模扫描：资金↑ → 换手/冲击↑ → 净收益↓；与拥挤联动砍仓。
