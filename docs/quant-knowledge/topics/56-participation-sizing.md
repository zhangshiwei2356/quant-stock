# 56 · 成交占比与参与率定仓（深化）

对照衔接 [20](20-execution-cost-impact.md)、[30](30-crowding-capacity.md)、[41](41-portfolio-impact.md)。

## 1. 缺口

批二/四已有冲击与容量，但选股买卖点常仍按「信号强度」定仓，忽略 **ADV 参与率**。大信号 × 小票 = 不可成交的纸面 Alpha。

## 2. 规则直觉

目标股数应同时满足：

- 账户风险预算（ATR/Heat）  
- 单日成交额占比上限（如 ≤ ADV 的数个百分）  
- 组合层同向冲击（[41](41-portfolio-impact.md)）  

取更严者。

## 3. 错误

回测假设 100% 成交；用复权价估 ADV；参与率上限只写文档不进撮合。

## 4. 本应用

已有冲击/滑点路径时可对照：开题把「参与率夹逼」写入仓位公式验收，与金叉信号解耦。
