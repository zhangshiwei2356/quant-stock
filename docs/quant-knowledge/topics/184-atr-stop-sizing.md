# 184 · ATR 止损与定仓一体

对照第十四万轮 AG01–AG05、AG26、AG33–AG35、AG60；衔接 [07](07-map-to-this-app.md)、[76](76-kelly-fractional-sizing.md)、[20](20-execution-cost-impact.md)。

## 1. 核心错误

止损与仓位割裂；固定点数；先仓后止损致风险 R 漂移；ATR 滞后政权切换；低波过紧/无地板；R 不含滑点；乘数海选。

## 2. 改法

**先定止损距（含 ATR 上下限）再定仓**；R 含滑点佣金；与金字塔/硬顶同检；参数预注册+样本外；止损属风控不改金叉方向。

## 3. 本应用

本应用已有 ATR 定仓/止损思路；知识库强调一体与门禁，不静默改 MA5/MA20 金叉。
