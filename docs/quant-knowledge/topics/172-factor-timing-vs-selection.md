# 172 · 因子择时与选股分册

对照第十二万轮 AE18–AE22、AE39、AE46、AE51；衔接 [114](114-multifactor-selection-pitfalls.md)、[156](156-signal-ensemble-gating.md)、[29](29-paradigm-matrix.md)。

## 1. 核心错误

择时权重并入选股分；混量纲海选；择时分直接开多；宏观择时覆写金叉；择时 IC 不监控。

## 2. 改法

**选股 / 择时 / 执行分册**；择时只做仓位缩放或过滤（只滤不开）；预注册规则+样本外计 N；滚动 IC + 漂移闸。

## 3. 本应用

主路径仍为金叉 + RSI 滤；择时若启用仅沙箱闸门，禁静默改方向。
