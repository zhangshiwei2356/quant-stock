# 165 · 部分成交与撤改

对照第十一万轮 AD13–AD18、AD45、AD47、AD71；衔接 [31](31-execution-gap-is.md)、[128](128-vwap-twap-execution.md)、[80](80-tick-lot-constraints.md)。

## 1. 核心错误

部分成交当噪声；撤单瞬时成功（删除毒成交）；改价仍保队列优先级；部成打乱仓位账/金字塔；佣金漏计。

## 2. 改法

成交台账状态机（Resting/Partial/PendingCancel）；**改价=撤补重置队尾**；建模撤单延迟；部成率日报；lot/成本按实际成交。

## 3. 本应用

部成属撮合假设层；主路径仍金叉+RSI 滤；账面≤80%、单票≤30%、金字塔 50/30/20 按成交后仓位校验。
