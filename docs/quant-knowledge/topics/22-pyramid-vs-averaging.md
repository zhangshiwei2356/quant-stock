# 22 · 加仓：金字塔 vs 摊平（对照本应用）

对照 ERRATA E25；对照 `rules.html` 金字塔节。

## 1. 定义对立

| | 金字塔（加赢） | 摊平 / 马丁（加亏） |
|--|----------------|---------------------|
| 条件 | 已有浮盈且趋势仍在 | 浮亏中降成本 |
| 仓位 | 后档通常更小 | 常等额或加倍 |
| 风险 | 止损上移，总风险可控 | 错误时风险指数放大 |
| 结果倾向 | 趋势利润放大 | 偶发大亏毁账户 |

## 2. 本应用语义（知识对照）

- 浮盈 ≥1%（相对综合成本）且 MA5>MA20  
- 切片相对满仓目标 **50% / 30% / 20%**（递减）  
- **不是**亏损加仓  

研发若改加仓规则：禁止改成马丁；加仓后应重算/上移止损并检查总风险预算。

## 3. 仍须防的错

- 震荡市金字塔 → 假突破堆仓  
- 加仓后不调止损 → 合并风险膨胀  
- 倒金字塔（后档更大）
