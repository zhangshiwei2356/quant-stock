# 16 · A股隔夜 / 日内 / 集合竞价（研发储备）

对照 [ERRATA E16–E17](../errata/ERRATA.md)。

## 1. 与美股相反的统计倾向（需自检验）

公开研究常报告：A股**隔夜（C2O）偏弱、日内（O2C）偏强**；美股常见隔夜溢价更强。  
原因讨论多与 **T+1**、开盘信息不对称、逆向选择折价有关——**当作待验假设，不作定律**。

## 2. 对买卖点的含义

| 错法 | 改法 |
|------|------|
| 收盘信号假设「吃隔夜红利」 | 评估对次日开盘、开盘后 30 分钟的贡献 |
| 盘中信号按 T+0 当日平仓回测 | A股无底仓时必须承担隔夜 |
| 用美股反转逻辑直接搬家 | 本土化：涨跌停、T+1、竞价 |

## 3. 集合竞价

- 9:15–9:20：可撤单 → 噪声/诱导多  
- 9:20–9:25：不可撤单 → 更可作订单流特征  
- 策略研发：竞价因子默认用后段；本应用分钟路径有开盘静默，方向一致  

## 4. 因子注意

- 勿把涨跌停日简单 drop 当「无信息」  
- 隔夜/日内因子拆开测 IC，再合成
