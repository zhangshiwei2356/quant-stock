# 191 · 三重屏障标签

对照第十五万轮 AH01–AH05、AH26、AH35、AH60；衔接 [87](87-meta-labeling.md)、[184](184-atr-stop-sizing.md)、[170](170-purged-cv-walkforward.md)。

## 1. 核心错误

固定地平线当路径依赖结果；训练屏障与回测规则不一致；调屏障把标签调「好预测」；垂直屏障审查/类别极不平衡不报；屏障标签改开仓方向。

## 2. 改法

屏障与止盈止损/时钟 **预注册对齐**；触及顺序与缺口规则显式；报标签分布；成本进路径；标签属研究层，不改金叉主信号。

## 3. 本应用

若用元标签/屏障，方向锁主信号（金叉）；只滤/定仓，不开反向。
