# 01 · 量化交易基础（A股视角）

## 1. 什么是「量化」

用**可重复的规则**把「选什么、何时买、买多少、何时卖、如何控风险」写成程序，再用历史数据检验（回测），再在模拟/实盘执行。

闭环通常是：

```
数据 → 特征/因子 → 信号 → 组合/仓位 → 撮合仿真 → 绩效评估 → 迭代
```

## 2. 研究 vs 交易两套世界

| 维度 | 研究（回测） | 交易（实盘/模拟） |
|------|-------------|------------------|
| 时间 | 可扫全历史 | 只能用「当时可见」信息 |
| 成交 | 需建模滑点/涨跌停 | 真实挂单与流动性 |
| 目标 | 统计显著性、稳健性 | 可执行、可风控、可运维 |

好的回测目标：**像真实交易**，不是做出完美净值曲线。

## 3. A股微观结构（必须进规则）

1. **T+1**：当日买入当日不可卖（可卖量按开仓批次日期算）。  
2. **100 股整数手**。  
3. **涨跌停**：主板约 ±10%，创业/科创约 ±20%；涨停难买、跌停难卖。  
4. **成本**：佣金（常有最低 5 元）、卖出印花税、过户费；另有滑点与冲击。  
5. **交易时段**：上午 9:30–11:30，下午 13:00–15:00；集合竞价与静默开盘需单独处理（深化见 [16-ashare-overnight-auction.md](16-ashare-overnight-auction.md)，**勿套用美股隔夜溢价假设**）。  
6. **停牌 / ST**：不可交易或风险标的，选股与开仓过滤应剔除。

参考开源脚手架对 T+1/手数/费用的建模思路：[china-astock-quant](https://github.com/MisakaMikoto128/china-astock-quant)。

## 4. 回测引擎常见模式

- **事件驱动**：按 K 线推进，易模拟 T+1、资金约束、涨跌停不成交。  
- **向量化**：算得快，但易漏微观结构，需手动补约束。  

信号日与成交日分离是防未来函数的关键：

- 日 K：收盘出信号 → **下一交易日开盘**（或可成交价）成交。  
- 分钟：信号后等待满足时间窗（如次日开盘后若干分钟）再成交。

## 5. 绩效怎么看（别只看收益率）

- 收益：总收益、年化、相对基准超额  
- 风险：最大回撤、波动、Calmar  
- 交易：胜率、盈亏比、换手、成本占比  
- 稳健：子区间、参数邻域、样本外
