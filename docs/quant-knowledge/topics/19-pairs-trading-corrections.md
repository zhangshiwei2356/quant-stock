# 19 · 配对交易纠错

对照 ERRATA E21–E22。

## 1. 相关 ≠ 协整

- 相关：收益同向  
- 协整：价差（残差）平稳、有锚  
只按相关开价差 → 价差可单边漂移。

## 2. 标准流程（诚实版）

1. 经济相关候选（同业/上下游），忌万人海选不校正  
2. Engle–Granger：回归 → 残差 ADF  
3. **滚动**对冲比 β（禁全样本 β）  
4. 滚动 μ/σ 得 z-score 入场  
5. 定期复检协整；失效平仓  
6. 点时选对 + 真实成本后看绩效  

公开案例：全样本 β 夏普尚可 → 改滚动后可转负 → 再修窗与成本后接近零——说明「看起来赚」常来自未来函数。

## 3. Kalman 注意

RTS 平滑用未来数据，**仅研究**；实盘用滤波前向更新。  
Q/R 与选对标准皆须点时。
