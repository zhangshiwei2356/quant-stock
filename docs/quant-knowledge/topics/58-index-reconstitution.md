# 58 · 指数调仓 / 成分套利

对照 ERRATA E106–E107；衔接 [44](44-universe-pit-survivorship.md)、[51](51-unlock-reduce-events.md)。

## 1. 机制

宽基定期按市值/流动性等规则调整；被动资金在生效前必须换仓 → **调入买压 / 调出卖压**预期。

## 2. 常见错

| 错 | 对 |
|----|----|
| 官方名单公布后才买调入 | 超额常已提前；公告后重估 |
| 用最终名单回测 | 前视；用当时可算规则 |
| 当作稳定 Alpha | 机构化后空间收窄；成本+抢跑 |

公告日 ≠ 生效日；须分列（同成分三日期契约）。

## 3. 本应用

主路径非调仓套利。可选：调出预期股降权/禁新开；独立沙箱勿并金叉。
