# 80 · 最小变动价与整手约束

对照 ERRATA E153、E163；衔接 [05](05-ashare-pitfalls.md)、[56](56-participation-sizing.md)、[31](31-execution-gap-is.md)。

## 1. 约束

A 股常见：**0.01 元**最小变动价、**100 股**整手（另有零股卖出等特例，以交易所/券商为准）。  
回测若按连续股数/任意价位，仓位与能否成交都会偏乐观。

## 2. 常见错误

- 任意小数股成交（E153）  
- 低价股相对 tick 成本被低估（E163）  
- 舍入后资金不足仍「成交」  

## 3. 改法

撮合层强制 tick 对齐与 lot 取整；报告披露因整手产生的**现金拖累**与拒单率。

## 4. 本应用

对照 `rules.html` 整手/涨跌停；知识库要求回测与实盘同一取整规则。
