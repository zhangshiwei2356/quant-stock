# 知识库纠错对照（ERRATA）

> 用途：记录「旧表述 → 问题 → 正确理解 → 研发启示」。  
> 原则：对比分析、发现错误、解析错误、优化解决。  
> 更新：2026-07-23 · 覆盖 R011–R110 迭代中识别的关键误区。  
> **非投资建议**；与本应用冲突时以 `rules.html` / 代码为准。

## E01 · RSI「超买就卖 / 超卖就买」

| | |
|--|--|
| **错误** | RSI>70 一律卖出，RSI<30 一律买入 |
| **解析** | 趋势市中 RSI 可长期停留超买/超卖区，表示动能强，不是反转保证 |
| **优化** | 先判 regime（如 ADX）：震荡→均值回归阈值；趋势→顺势回撤区（如上升趋势买 RSI 回落至 40–50） |
| **对本库** | 本应用用 RSI\<60 作金叉过滤（防追极端），≠「超卖抄底」；勿混用 |
| **轮次** | R015–R018 |

## E02 · 均线金叉「无过滤必赚」

| | |
|--|--|
| **错误** | 每根金叉都开仓 |
| **解析** | 震荡市 whipsaw；无过滤胜率常仅约 35–40%（公开回测量级，不可外推） |
| **优化** | 大周期趋势过滤 + ADX + 放量 + RSI 区间；EMA/SMA 按持仓周期匹配 |
| **对本库** | 可选 MA60/ADX/放量；默认 RSI/ATR 硬过滤 |
| **轮次** | R011–R014 |

## E03 · EMA 一定优于 SMA

| | |
|--|--|
| **错误** | 永远用 EMA「更快更好」 |
| **解析** | EMA 更灵敏也更多假信号；SMA 更平滑更滞后 |
| **优化** | 短线/急变用 EMA；波段确认用 SMA；或长 SMA 定趋势 + 短 EMA 择时 |
| **轮次** | R012 |

## E04 · MACD 背离必反转

| | |
|--|--|
| **错误** | 出现背离就反向开仓或提前平仓 |
| **解析** | 急涨后常态减速也会背离（假阳性）；横盘时 MACD 向零轴回归几乎总「背离」 |
| **优化** | 以价格结构确认（高低点破位）再行动；背离不作唯一出场 |
| **轮次** | R019–R020 |

## E05 · ATR 止损越紧越好

| | |
|--|--|
| **错误** | 固定 1×ATR 或极紧百分比移动止盈 |
| **解析** | 1×ATR 常被噪声扫出；跳空使止损价≠成交价 |
| **优化** | 波段常用 2×ATR；仓位按 \(Equity\times r/(k\cdot ATR)\)；事件前降仓 |
| **对本库** | 止损约 2×ATR + 权益 2% 夹逼；trail 1.5×ATR |
| **轮次** | R021–R025 |

## E06 · 因子 t>2 就显著

| | |
|--|--|
| **错误** | 按单次检验 t=2（p=0.05）宣称发现 alpha |
| **解析** | 多重检验下伪发现极高；Harvey et al. 建议约 t≥3；模拟研究甚至更高 |
| **优化** | 收紧阈值、样本外、经济逻辑、发表后衰减预期（约腰斩量级） |
| **轮次** | R031–R035 |

## E07 · PE 直接排序选「便宜」

| **优化** | 用 E/P；负利润单独处理；公告日 PIT |

## E08 · 「行业减均值」=中性化

| | |
|--|--|
| **错误** | 只做行业内减均值就算市值+行业中性 |
| **解析** | 无法同时控制交叉暴露；极值干扰大 |
| **优化** | 截面回归：因子 ~ log(市值) + 行业哑变量，取残差；先去极值再回归 |
| **例外** | 部分强行业属性因子不宜强行中性化 |
| **轮次** | R039–R040 |
