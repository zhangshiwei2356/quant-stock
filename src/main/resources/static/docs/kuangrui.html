二、文档分析（手册要点）

2.1 协议共性
  • TCP Socket + 二进制报文（MDS 另有 UDP 组播）
  • 价格/金额：整型，精确到元后四位，1 元 = 10000
  • 登录：ClientLogonReq/Rsp；clEnvId∈[0~99]；密码 encryptType 须与柜台一致
  • 配置改 JSON，勿把 Demo 样例 IP/账号写进仓库
2.2 MDS 行情手册

入口：MdsClient（TCP）/ MdsUdpClient（组播）；回调 MdsCallBack / MdsUdpCallBack。定位是实时行情，不是历史 K 线库。

能力典型接口 / 回调对本应用价值
行情订阅subscribeMarketData → L1 股票/指数/期权实盘扫描、盘中价
Level2L2 快照/增量/逐笔委托成交、最优档等深度；资金流可自算近似（后置）
快照查询qryMktDataSnapshot / qrySnapshotList补洞、启动拉全量
证券实时状态qrySecurityStatus / onSecurityStatus停复牌硬过滤
交易时段qryTrdSessionStatus / onTrdSessionStatus开市/休市/集合竞价
证券静态信息qryStockStaticInfo / List（涨跌停、停牌、股本等）替换启发式市值/涨跌停
UDP 组播MdsUdpClient低延迟；部署门槛高，第一刀不做

MDS 不覆盖：多年历史日/分钟 K、复权因子、财报、舆情。回测仍靠本地库或其他源。

2.3 OES 交易手册

入口：OesClient；三通道：委托 / 回报 / 查询；回调 onOrd / onRpt / onDisConn。本应用只规划现货。

能力典型接口对本应用价值
下单 / 批量 / 撤单sendOrdReq / sendBatchOrdsReq / sendOrdCancelReq替换 trade-mode=sdk 桩
回报同步sendRptSync（手册有 initRptSync 演进）登录后必做；超时易断连
查委托 / 成交queryOrder / queryTrade真柜台版 sync-orders
查资金 / 持仓queryCashAsset / queryStkHolding真 position-pnl-sync
总览 / 柜台资金queryClientOverview / queryCounterCash纸面对账
佣金 / 产品 / 交易日queryCommissionRate / queryStock / queryTradingDay 等费率与过滤增强
两融 / 期权 / ETF / 银证大量扩展接口超出现货金叉范围，暂缓

文档难点在运维契约（换算、回报同步时限、环境号、加密、重连），不是缺接口名。

三、Demo 代码分析

  • Main：交互选 oes / MDS(TCP|UDP)；测试账号写死 customer1/123456；默认现货
  • OesExample 推荐顺序：创建code>OesClientImpl → initCallBack → start(logon) → 用 lastInMsgSeq 初始化流水 → sendRptSync → 再查账户/下单。样例价 ordPrice=300000 即 30 元
  • MdsExample：登录 → subscribeMarketData → L1/L2 回调 + 静态/状态/时段查询
  • MdsUdpExample：组播收流；第一刀用 TCP L1，UDP/L2 后置
  • 回调注释要求：生产用 RingBuffer + 工作线程，勿阻塞 API 线程
  • 工程形态：本地 jar + lib，非 Maven 中央坐标；含 API-Tester

M0 当前状态（2026-07-26 · 阿里云模拟）
  • 脚手架：已就绪 · config/kuangrui/、scripts/kuangrui/m0-env-check.ps1、M0LoginProbe；本应用联通测试 KuangruiLoginConnectivityTest（Maven -Pkuangrui，对齐 Demo 登录三步）
  • 资料包 / JDK：官方 jar 0.17.6.4（运行日志 ApplVerId 0.17.6.3）；本机 Java 21 可编译运行探针
  • 阿里云模拟地址（非实盘）：OES 106.15.58.119 ord/rpt/qry=6101/6301/6401；MDS 139.196.228.232 tcp/qry=5103/5203 — TCP 全部可达
  • 登录探针：TCP 握手成功后卡在 Pre Logon，OES/MDS 均 errorCode=1045（Java 枚举无此码，映射为 OTHER_ERROR）。手册 V0.17.6 错误表只到 1043，换 encryptType/clEnvId/显式 IP·MAC 无效（预登录阶段尚未验密）
  • 复现 1045：配置 local + 环境变量后执行 mvn -Pkuangrui test -Dtest=KuangruiLoginConnectivityTest 或 .\scripts\kuangrui\m0-env-check.ps1 -RunLoginProbe；日志应出现 Pre Logon ... 1045
  • M0_STATUS：BLOCKED（网络已通，预登录被拒）。需向宽睿确认账号/API 版本。通过后同上命令应登录成功 → M0_STATUS=COMPLETE
  • 密钥只放 config/kuangrui/local/（已 gitignore）+ 环境变量；勿提交仓库
