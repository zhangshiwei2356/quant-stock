二、手册要点（V0.19.4）

2.1 协议共性
  • TCP Socket + 二进制报文（MDS 另有 UDP 组播）
  • 价格/金额：整型，精确到元后四位，1 元 = 10000（本应用落库前÷10000，库内一律「元」）
  • 登录：ClientLogonReq/Rsp；clEnvId∈[0~99]；密码加密类型须与柜台一致
  • 配置走外部 JSON；通道配置在 config/kuangrui/local/（gitignore）
  • 账号：优先「宽睿联调 → 账号登录」验柜后入库（用户名明文、密码 AES-GCM；主密钥在 kuangrui_crypto_key，同库仅防误读）；否则 QUANT_KUANGRUI_USER/PASSWORD。进入账号页自动请求 GET /api/ops/kuangrui/account/current 展示 currentUsername（无密码）。勿把密码写进 yml/Git；数据表白名单不含密钥/账号表
2.2 MDS 行情

入口：MdsClient（TCP）/ MdsUdpClient（组播）；回调 MdsCallBack / MdsUdpCallBack。定位是实时行情，不是多年历史 K 线库。

能力典型接口 / 回调对本应用
行情订阅subscribeMarketData → L1 股票/指数/期权M1 已用：目标池 L1 → 分钟桶
快照查询qryMktDataSnapshot / qrySnapshotListM1 已用：pull 补当前分钟
Level2L2 快照/增量/逐笔等后置
证券实时状态qrySecurityStatus / onSecurityStatusM4 已用：停复牌（可开关回退量≤0）
交易时段qryTrdSessionStatus / onTrdSessionStatusM4 已用：开市/休市查询
证券静态信息qryStockStaticInfo / ListM4 已用：涨跌停/停牌/股本
UDP 组播MdsUdpClient低延迟；公网模拟通常不可用，后置

MDS 不覆盖：多年历史日/分钟 K、复权因子、财报、舆情。回测仍靠本地库 / TDX 等。

2.3 OES 交易（现货）

入口：OesClient；三通道：委托 / 回报 / 查询；回调 onOrd / onRpt / onDisConn。本应用只规划现货。

能力典型接口对本应用
下单 / 批量 / 撤单sendOrdReq / sendBatchOrdsReq / sendOrdCancelReqM3 已用：限价报/撤（批量后置）；oes.order-enabled 总闸
回报同步sendRptSync登录后必做；超时易断连
查委托 / 成交queryOrder / queryTradeM2/M3：对账 + sync 推进补强
查资金 / 持仓queryCashAsset / queryStkHoldingM2 已用：运维查询 + position-pnl-sync 对账
总览 / 柜台资金queryClientOverview / queryCounterCash纸面对账
佣金 / 产品 / 交易日queryCommissionRate / queryStock / queryTradingDayM4 已用：可开关覆盖本地费率/日历/涨跌停
两融 / 期权 / ETF / 银证扩展接口族超出现货范围，暂缓
2.4 常用错误码

ErrorCode： 1045 = OESERR_INVALID_USERNAME_OR_PASSWORD、 1046 = OESERR_PASSWORD_LOCKED、 1047 = OESERR_ILLEGAL_OPTIONAL_INPUT_SOURCE。 Pre Logon 报 1045 时优先核对账号开通、用户名/密码与加密类型。

三、Demo 用法（v0.19.4.0）

  • all/demo/Main：交互选 OES / MDS(TCP|UDP)；默认现货；测试账号勿入库
  • OesExample：建 OesClientImpl → initCallBack → start(logon) → 用 lastInMsgSeq 初始化流水 → sendRptSync → 再查账户/下单。样例价按「元后四位」（如 300000 = 30 元）
  • MdsExample：登录 → subscribeMarketData / 快照查询 → L1/L2 回调 + 静态/状态/时段查询
  • MdsUdpExample：组播收流；当前主路径用 TCP L1
  • 回调勿做重活：生产用队列 + 工作线程，勿阻塞 API 线程
  • 工程形态：本地 jar + lib（Maven profile kuangrui 引入）；含 API-Tester

阶段目标要点Done 标准
M5a MDS 连接韧性（优先） 现状：onDisConn 只清 subscribed，不清 client； ensureClient 见非空直接返回 → 易顶死连接； market-collect pull 空窗时仍可能 return true 挡住本地回退。 改：异步 closeClient → 退避重登 → 需则重订阅；全失败勿冒充成功。 断线后采集可自愈或明确回退本地；status 可见断线/重连
M5b OES 连接韧性 现状：断线置 client=null 可懒重连，但未先 close（泄漏/重复登录风险）。 改：先 close 再重建 + sendRptSync；退避；status 暴露断线计数。 断线后只读/报撤可恢复；仿真无长期假死
M3/M5 小修 状态与撤单 粗映射已有（含 REJECTED≥10）。缺口： PARTIALLY_CANCELED(6) 现映 PARTIAL，应映 CANCELLED（保留已成量）； 撤单现乐观本地 CANCELLED，应等回报/查询确认。 单测覆盖状态 6；撤拒不永久假撤

六、启用前置

  1. 宽睿侧开通 OES、MDS 账号与通道（仿真可用上文阿里云地址）
  2. 本机 mvn install:install-file 安装 quant360-all-api-0.19.4.0.jar；以 -Pkuangrui 运行/打包
  3. 准备 config/kuangrui/local/mds_api_config.json（及 OES 配置）；在「宽睿联调 → 账号登录」验柜入库，或设 QUANT_KUANGRUI_USER / PASSWORD
  4. 长连接：登录、心跳、断线重连（见 M5）、回报续订；回调勿做重活（参考 Demo）；明确仿真 vs 生产、clEnvId 与加密
