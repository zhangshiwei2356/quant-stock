按注册策略查看详细介绍、综合评分与回测历史。本页只做效果总览；改参 / 激活仍在「运维中心 → 运行参数」。

能力能做什么

  • 左侧 280px 列表（激活/等级标签统一）；名称尽量单行不折行
  • 综合评分通栏卡 + 分项/聚合指标网格；介绍默认收起
  • 历史表精简列，可按类型筛选、按时间/收益率排序；点行展开区间与成交等详情
  • 无回测时自动用目标池补种（逐只单股 + 全池组合）

步骤怎么开始

  1. 点「策略总览」进入工作台
  2. 左侧选策略，展开介绍，看评分分项与回测列表
  3. 需要改参或切换激活策略 → 运维中心

本页为可选模块介绍（顶栏「帮助」可打开）。日常请从侧栏二级菜单或首页入口直接进入功能；点顶栏 Logo 回首页仪表盘。
