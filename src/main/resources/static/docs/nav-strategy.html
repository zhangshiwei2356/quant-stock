按注册策略查看详细介绍、综合评分与回测历史。本页只做效果总览；改参 / 激活仍在「运维中心 → 运行参数」。

能力能做什么

  • 左侧列出已注册策略（含综合评分徽章）；当前激活策略带角标
  • 策略介绍默认收起，可展开查看买卖逻辑与用途说明
  • 无回测时自动用目标池补种（逐只单股 + 全池组合），并显示进度
  • 卡片展示满分 100 的加权评分与聚合指标；历史表点行可看详情

步骤怎么开始

  1. 点「策略总览」进入工作台
  2. 左侧选策略，展开介绍，看评分分项与回测列表
  3. 需要改参或切换激活策略 → 运维中心

评分来自历史回测加权（收益/回撤/胜率/盈利占比/样本），样本少时仅供对照。旧回测若无 strategy_id 不会计入。再点一次「策略管理」可收起并回初始化页。
