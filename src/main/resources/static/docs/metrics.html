评价策略时，除了「赚了多少」，还要看回撤、夏普、胜率与交易频率，避免只看终点收益。下列口径与本应用回测落库 / 策略总览一致。

收益与权益

  • 权益 = 现金 + 持仓市值（已含佣金、印花税、滑点等成交成本）
  • 总收益率 totalRate = (期末权益 − 初始资金) / 初始资金
  • 期末资产 finalAsset：回测结束日按收盘价盯市后的权益
  • 组合回测另有分股贡献（各标的对总收益的近似贡献，不是独立账户年化）

最大回撤（峰值回撤）

  • 定义：权益曲线上，从历史最高点到之后某点的最大跌幅
  • 公式：某一时刻回撤 = (历史最高权益 − 当前权益) / 历史最高权益；全程取最大值 → maxDrawDown
  • 含义：衡量「从高点亏掉多少」的路径风险；高收益伴随高回撤时，应对照账户熔断、仓位系数是否过大
  • 本应用不单独计算 Calmar（年化收益/最大回撤）；需要时可用总收益与回撤自行粗估，注意区间长度不同不可横比

夏普比率（Sharpe）

衡量「单位波动换来多少超额收益」。本应用落库字段 sharpe，策略总览展示 avgSharpe。

  • 本系统算法（见 SharpeRatioCalculator）：
    • 从权益曲线取相邻点简单收益：r_t = E_t / E_{t-1} − 1
    • 无风险利率 RF = 0（未扣国债利率）
    • 样本均值 / 样本标准差（除以 n−1），再乘年化因子 √N
    • 年化期数 N：日线 252；周 52；月 12；分钟按约 240 分钟/交易日 × 252（并按 5/15/30/60 分钟缩放）
    • 有效收益点 < 2、标准差为 0、权益非正 → 记为空白（null）
  • 展示位置：回测历史落库列「夏普」；策略总览平均夏普与说明「年化夏普（RF=0）」
  • 重要：夏普仅展示，不计入综合评分（满分 100 的加权里不含夏普）
  • 阅读注意：短样本、交易极少或收益几乎常数时夏普不稳定或为空；不同周期（日/分钟）年化方式不同，不宜直接横比；旧回测若当时无权益曲线则无夏普列

胜率

  • 口径：盈利的完整开平回合数 / 全部完整开平回合数（不是按每一笔委托或每一根 K）
  • 无完整回合时记 0；组合回测另有分股胜率汇总
  • 胜率高但盈亏比差、或回合极少，都要结合权益曲线与回撤看

综合评分（策略总览）

基于该策略已落库回测摘要加权，满分 100，不是实盘预测。权重大致为：

  • 收益 30（平均总收益率）
  • 回撤 25（平均最大回撤，越小越好）
  • 胜率 20
  • 盈利占比 15（总收益 > 0 的回测条数占比）
  • 样本 10（回测次数，≥10 次该项满分）

无回测记录时评分为空。夏普只旁路展示。

其它本应用相关字段

  • tradeStats：买卖次数/股数/手数/成交额、费用合计、总盈亏等（工作台结果区）
  • 综合成本（单票）：Σ(买入成交额 + 买入佣金) / 股数
  • configFingerprint：策略相关配置指纹（v1:<16hex>），便于对照「同一套参」的实验
  • atrRisk：ATR 止损/移动止盈等风控路径的验收摘要（含止损出场次数等），见交易规则 / ATR 知识页

阅读建议

  • 优先看权益曲线形状，再看总收益、回撤、夏普、胜率
  • 批量扫描多按总收益率排序，门槛与单股完整回测不完全相同
  • 换区间、换标的、改指纹后，旧夏普与评分不可直接当「策略变强」证据
