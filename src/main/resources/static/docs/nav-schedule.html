管理预置定时任务，并查看数据健康与运行参数。任务配置写入 MySQL，改完立即重载。

二级菜单说明

  • 任务管理：启停 / 改 cron；「执行一次」弹出进度框（阶段、进度条、当前动作），页内同步横幅，可收起到页内；长任务有 i/n 百分比
  • 数据健康：覆盖检查（待处置告警 vs 特殊项）/ 分钟自洽 / MDS·TDX 抽样对账
  • 运行参数：全局 quant.prop.* + 策略包 strategy_param；其余 yml 只读；已注册策略列表与纸面激活切换

步骤建议流程

  1. 确认 MySQL 已建库且 quant.db-enabled=true
  2. 在「任务管理」只打开需要的任务并核对 cron
  3. 用「数据健康」核对行情是否滞后后再开扫描

再点一次「运维中心」可收起并回初始化页。
