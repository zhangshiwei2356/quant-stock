管理量化交易的唯一目标池。二级菜单查看当前池名单与历次扫描入选报告；盘后扫描自动覆盖；人工可移出（移出≠卖出）。

二级菜单说明

  • 当前池：可买名单 + 扫描漏斗（无数据时引导扫描）；入池原因截断悬停查看
  • 扫描历史：按批次查看历次入选；也可在此手动「扫描更新」
  • 扫描更新：主按钮，提交 pool-rebuild（异步进度弹框）；「下载报告」为文字链接
  • 移出：悬停变红，二次确认（移出≠卖出）；「刷新列表」只重载不扫描

步骤建议流程

  1. 漏斗为空时点「扫描更新」生成数据，或开启定时 pool-rebuild
  2. 不需要的标的在当前池点「移出」并确认（移出≠卖出）
  3. 在「扫描历史」核对某批次入选名单
