Quant Stock 是基于 Spring Boot 2.7 + TA4J 的 A 股量化回测与模拟交易单体应用（非前后端分离）。页面在 static/，接口在 /api/**，数据默认落本地 MySQL quant_stock。

如何启动

  • 项目根目录：执行 mapper/schema.sql 后 mvn spring-boot:run
  • 浏览器：http://localhost:8080/stock.html
  • 空库自动导入 1 分钟种子（有 MIN_1.json 则用之，否则由 MIN_5.json 拆成 1 分钟）

默认行情 / 交易模式

  • quant.market-mode=db（行情从哪来）：K 线只读本地 MySQL market_1min；5/15/30/60/日/周/月一律内存聚合。空库启动自动灌演示 1 分钟种子。可选 json（classpath JSON，偏开发）、sdk（外部行情客户端，当前多为桩；宽睿 MDS 尚未接入主路径）
  • quant.trade-mode=sim（单怎么成交）：本地模拟账本——下单即时 FILLED 并改现金/持仓，可持久化；不连券商柜台。可选 sdk：先 SUBMITTED 占资/占仓，由 sync-orders 再推进成交（当前仍为本地桩；宽睿 OES 尚未替换）
  • 二者组合含义：默认开箱即用「库内行情 + 本地模拟成交」，可回测/扫池/纸面账户，无需宽睿或券商账号

架构一览

  • 前端：stock.html + stock-chart.js；文档片段 static/docs/*.html
  • 后端包：market 行情 · strategy 策略 · backtest 回测 · pool 目标池 · trade 下单账本 · risk 风控 · task 调度 · account/admin 账户与运维 · pdf 文档
  • 数据：行情表 + 目标池 + 模拟账本 + 回测历史 + sys_schedule_job
  • 完整架构图与接口表见侧栏「项目 README」（实时渲染仓库 README.md）

功能模块

  • 行情浏览：全市场模糊选股、多周期 K 线与指标
  • 个股回测：回测工作台仅从目标池选股（含策略下拉；可选 branchScaffold；可展开「本次临时参数」不落库）/ 批量扫描 / 回测历史
  • 组合回测：目标池多选；默认日 K 共享资金池；branchScaffold 时 session 为 MIN_1 共享资金池（账户风控/熔断挂卖/AUM+POV，无金叉五步；结果含会话事件与相关摘要）；可临时改参 / 回测历史
  • 目标池：当前池 / 扫描历史；盘后或手动扫描覆盖唯一池；移出≠卖出；也是回测选股来源
  • 账户概览：资金 · 持仓（T+1 批次）· 委托 · 日结 · 风控事件
  • 运维中心：任务管理 / 数据健康 / 运行参数（全局白名单 + 按策略稀疏参数包；已注册策略列表与纸面激活切换；任务种子默认全关）
  • 数据表：白名单表分页只读；侧栏/摘要展示磁盘占用（数据+索引）
  • 量化知识 / 应用说明：指标与规则文档；应用说明含系统概述、项目 README、交易规则、能力与待办、宽睿梳理；可导出 PDF

模拟数据与默认参数

  • 演示股：模拟五只（空库灌 market_1min）；目标池用 fetch_min1_tdx.py --from-pool 回填约 90 交易日 1 分钟
  • 物理真相源：仅 market_1min；更大周期内存聚合。灌数：python scripts/fetch_min1_tdx.py --from-pool 或 --codes 600036
  • 回测区间默认留空 = 全量 K 线；初始资金默认 100000
  • 页头主题默认日间（夜盘 / 银河 / 极光可切换并记住）

策略与风控摘要

  • 单活策略：默认 maCross（读全局过滤）；对照画像与脚手架 branchScaffold（session/MIN_1；默认 fill-mode=AUTO 对齐经典次日≥09:45 开盘；脚手架不下单；结果含分支绩效与事件表）可在回测下拉对比；纸面激活会话策略时走 SessionPaperAdaptor（默认开，quant.session.paper-enabled）
  • 金叉可配 MA60 / 放量 / ADX / RSI；综合成本止损、移动止盈；T+1 分档；金字塔 50/30/20
  • 撮合：日 K 下一根开盘；分钟 ≥ 次日 09:45；涨跌停主板 10% / 创科 20%
  • 单笔 ADV 参与率硬顶默认 10%（quant.max-participation-adv）；回测结果带配置指纹
  • 账户「纸面对账」；回撤深度+持续期；策略退役；止损跳空穿价按开盘；组合相关告警
  • 告警分级冷却 + 软预算 WARN；滑点残差日报；涨跌停限价夹紧（无五档）
  • 压力情景（ADV断崖降仓）；回测部成比例；信号漂移监控（默认不自动退役）
  • 多源对账闸（日线↔分钟聚合）；扩容降频+POV；结构突变挂漂移/降仓
  • ST as-of 禁开；换手软/硬顶；印花税政策 as-of；行业 reclass 日志（财报时钟仍缺）
  • IC 衰减监控（代理 IC→只降仓）；改价=撤补队尾；配置指纹含实验种子
  • 回测 atrRisk 验收字段；信号漂移标明代理 IC；禁空头边界可查
  • 限价/执行/对账/行业边界可查；组合回测对齐部成/压力降仓/成交缩量/停牌拒卖/ST as-of 强平/`atrRisk`；退役强制恢复双人复核
  • 账户「风控日报」含相关监控；委托支持撤/部成/改价；运维数据健康可跑对账闸；scan/sync/settle 锁忙手动执行 failLoud
  • 单股 / 组合 / 扫描交易对齐核心规则；实盘为本地模拟账本（含风控/挂单持久化与路径对齐）
  • 宽睿 OES/MDS：见「宽睿文档梳理」；M0 脚手架就绪，可用 mvn -Pkuangrui test -Dtest=KuangruiLoginConnectivityTest 复现预登录 1045（仍 BLOCKED，未进 M1）；默认仍 sim+db
  • 细则：「应用说明 → 交易规则」

可选能力

  • 定时总闸 quant.schedule.enabled；API：GET /api/schedule
  • 安全：可选 QUANT_API_KEY；限流 QUANT_RATE_LIMIT
  • 扩展：KlineSdkClient / trade-mode=sdk（当前为桩）
