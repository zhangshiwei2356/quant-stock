Quant Stock 是基于 Spring Boot 2.7 + TA4J 的 A 股量化回测与模拟交易单体应用（非前后端分离）。页面在 static/，接口在 /api/**，数据默认落本地 MySQL quant_stock。

如何启动

  • 项目根目录：执行 mapper/schema.sql 后 mvn spring-boot:run（或 IDEA 运行主类）
  • 默认 profile=local：叠加 application-local.yml（本机可开宽睿开关）；基线 application.yml 宽睿仍默认关
  • 宽睿真客户端另需 Maven profile kuangrui + config/kuangrui/local；账号优先「宽睿联调 → 账号登录」验柜入库，否则环境变量；浏览器：http://localhost:8080/stock.html
  • 空库自动导入 1 分钟种子（有 MIN_1.json 则用之，否则由 MIN_5.json 拆成 1 分钟）

默认行情 / 交易模式

  • quant.market-mode=db（行情从哪来）：分钟读 MySQL market_1min（5/15/30/60 内存聚合）；日线默认优先 market_daily（quant.day-source=auto，空则分钟聚日）。空库启动自动灌演示 1 分钟种子。可选 json（classpath JSON，偏开发）、sdk（外部行情客户端，当前多为桩）。宽睿 MDS L1 为旁路：基线 yml 默认关；本机 application-local.yml 可开，真客户端需 mvn -Pkuangrui
  • quant.trade-mode=sim（单怎么成交）：本地模拟账本——下单即时 FILLED 并改现金/持仓，可持久化；不连券商柜台。可选 sdk：先 SUBMITTED 占资/占仓，由 sync-orders 再推进成交（默认本地桩；宽睿 OES 报撤为可选旁路，需 oes.order-enabled）
  • 二者组合含义：默认开箱即用「库内行情 + 本地模拟成交」；本机 local 开宽睿开关后仍须 -Pkuangrui 才 live

架构一览

  • 前端：stock.html + stock-chart.js；文档片段 static/docs/*.html；顶栏与标签页使用 ZSW 品牌图标（/favicon.ico、/images/logo.png）
  • 后端包：market 行情 · strategy 策略 · backtest 回测 · pool 目标池 · trade 下单账本 · risk 风控 · task 调度 · account/admin 账户与运维 · pdf 文档
  • 数据：行情表 + 目标池 + 模拟账本 + 回测历史 + sys_schedule_job
  • 完整架构图与接口表见侧栏「项目 README」（实时渲染仓库 README.md）

功能模块

  • 行情浏览：全市场模糊选股、多周期 K 线与指标
  • 个股回测：回测工作台仅从目标池选股（含策略下拉；可选 overnightGap 走 session/MIN_1；可展开「本次临时参数」不落库）/ 批量扫描 / 回测历史（落库带策略 id）
  • 组合回测：目标池多选；默认日 K 共享资金池；overnightGap 等会话策略为 session MIN_1 共享资金池（账户风控/熔断挂卖/AUM+POV，无金叉五步；结果含会话事件与相关摘要）；可临时改参 / 回测历史（落库带策略 id）
  • 目标池：当前池 / 扫描历史；「扫描更新」提交运维任务 pool-rebuild（异步进度弹框，与定时入池同一套）；可下载 PDF 报告；移出≠卖出；也是回测选股来源
  • 账户概览：资金 · 持仓（T+1 批次）· 委托 · 日结 · 风控事件
  • 运维中心：任务管理 / 数据健康（覆盖检查：待处置告警 vs 特殊项分表；分钟自洽；MDS/TDX 抽样对账） / 运行参数（全局白名单 + 按策略稀疏参数包；已注册策略列表与纸面激活切换；任务种子默认全关）
  • 策略管理：二级「策略总览」——注册策略介绍（默认收起）、满分 100 综合评分与回测历史；无回测时自动用目标池补种（逐只单股+全池组合）；空白/指纹旧名启动自动补全；不改参/不激活（仍在运维运行参数）
  • 数据表：白名单表分页只读；侧栏/摘要展示磁盘占用（数据+索引）
  • 宽睿联调：接入总览 + 账号登录（验柜后密文入库，DB 优先于 env）+ OES 只读 / MDS 行情 / 报撤左右分栏；报撤须 order-enabled+二次确认；开关见 application-local.yml（基线 yml 仍默认关）
  • 量化知识 / 应用说明：指标与规则文档；应用说明含系统概述、项目 README、交易规则、能力与待办、宽睿梳理；可导出 PDF

模拟数据与默认参数

  • 演示股：classpath 十只近一年模拟种子（空库灌 market_1min，区间随 MockKlineDataGenerator 重刷）；目标池可用 fetch_min1_tdx.py --from-pool 回填约 90 交易日 1 分钟
  • 行情分层：market_1min=池内交易分钟真相源；market_daily=全市场选股日线真相源（首期不复权 NONE）。日线灌数：python scripts/fetch_daily_tdx.py --from-basic --years 1；分钟灌数：python scripts/fetch_min1_tdx.py --from-pool
  • 入池流水线：日线入库 → factor-daily-rebuild（可选；pool-rebuild 默认不预刷）→ pool-rebuild（默认轻量扫池，pool-rebuild-full-backtest=false）→ 池内补分钟。数据健康：全市场看日线、池内看分钟；待处置告警与特殊项（北交所/退市·PT/停牌）分表
  • 推荐手动三步（定时任务默认关，运维「执行一次」）：① day-collect 全市场日线（同步列表；已齐跳过、否则增量；默认4线程）→ ② pool-rebuild 入池 → ③ pool-minute-backfill 池内分钟（尽量~90日并补到最近）。依赖本机 Python + pytdx/pymysql（quant.tdx-script.enabled 默认 true）。全部任务「执行一次」均后台跑：弹框 + 任务管理页内横幅同步进度，可「收起到页内」；长任务（TDX 日线/分钟、因子重算、入池、数据校验、行情采集）上报行级 i/n；入池若开预刷则分「因子预刷 → 粗筛扫描」两段进度
  • 回测区间默认留空 = 全量 K 线；初始资金默认 100000
  • 页头主题默认浪花（浅色日间：左下起浪、向右渐高 + 飞沫）；另有夜盘 / 银河，可切换并记住

策略与风控摘要

  • 单活策略：默认 maCross（读全局过滤）；对照画像 maCrossBalanced 与会话策略 overnightGap（隔日高开三分支：尾盘布局 / 早盘兑现或止损 / 盘中回撤；最长 2 日；session/MIN_1；阈值 quant.session.overnight-gap.*）可在回测下拉对比；已下线 maCrossTrend/maCrossVolume/maCrossStrict 与脚手架 branchScaffold；纸面激活会话策略时走 SessionPaperAdaptor（默认开，quant.session.paper-enabled）
  • 金叉可配 MA60 / 放量 / ADX / RSI；综合成本止损、移动止盈；T+1 分档；金字塔 50/30/20
  • 撮合：日 K 下一根开盘；分钟 ≥ 次日 09:45；涨跌停主板 10% / 创科 20%
  • 单笔 ADV 参与率硬顶默认 10%（quant.max-participation-adv）；回测结果带配置指纹
  • 账户「纸面对账」；回撤深度+持续期；策略退役；止损跳空穿价按开盘；组合相关告警
  • 告警分级冷却 + 软预算 WARN；滑点残差日报；涨跌停限价夹紧（无五档）
  • 压力情景（ADV断崖降仓）；回测部成比例；信号漂移监控（默认不自动退役）
  • 分钟行情自洽检查（空/滞后/稀疏/OHLC；默认不阻断）；扩容降频+POV；结构突变挂漂移/降仓
  • ST as-of 禁开；换手软/硬顶；印花税政策 as-of；行业 reclass 日志（财报时钟仍缺）
  • IC 衰减监控（代理 IC→只降仓）；改价=撤补队尾；配置指纹含实验种子
  • 回测 atrRisk 验收字段；信号漂移标明代理 IC；禁空头边界可查
  • 限价/执行/对账/行业边界可查；组合回测对齐部成/压力降仓/成交缩量/停牌拒卖/ST as-of 强平/`atrRisk`；退役强制恢复双人复核
  • 账户「风控日报」含相关监控；委托支持撤/部成/改价；运维数据健康可「检查分钟自洽」与「MDS/TDX 抽样对账」；scan/sync/settle 锁忙手动执行 failLoud
  • 单股 / 组合 / 扫描交易对齐核心规则；实盘为本地模拟账本（含风控/挂单持久化与路径对齐）
  • 宽睿 OES/MDS：资料包 v0.19.4.0；见「宽睿文档梳理」。M0 COMPLETE；M1～M4 均为可选旁路（默认关）；下一步 M5 连接韧性（先 MDS）；报撤需 oes.order-enabled+trade-mode=sdk；默认仍 sim+db
  • 细则：「应用说明 → 交易规则」

可选能力

  • 定时总闸 quant.schedule.enabled；API：GET /api/schedule
  • 安全：可选 QUANT_API_KEY；限流 QUANT_RATE_LIMIT
  • 扩展：KlineSdkClient / trade-mode=sdk（当前为桩）
