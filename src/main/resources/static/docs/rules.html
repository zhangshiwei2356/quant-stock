本页为应用规则说明（策略买卖、撮合成本、风控、单股/组合/批量扫描/实盘差异、页面与落库）。 以 application.yml → quant.* 与单股 BackTestEngine 为准；组合/实盘差异见专节。 改配置后需重启，并同步更新本页。

一、统计口径

  • 权益 = 现金 + 持仓市值（成交已含佣金、印花税、滑点与冲击成本）
  • 峰值回撤 = (历史最高权益 − 当前权益) / 历史最高权益
  • 总收益率 = (期末权益 − 初始资金) / 初始资金
  • 胜率 = 盈利的完整开平回合数 / 全部完整开平回合数
  • 综合成本（单票）= Σ(买入成交额 + 买入佣金) / 股数（不含印花税）
  • 成交汇总 tradeStats：买卖次数/股数/手数/成交额、费用合计、总盈亏(=期末−初始)

二、买入何时触发

  • 单活策略：同一时刻只跑 quant.active-strategy（默认 maCross，读全局 quant 过滤）。另有对照画像 maCrossTrend（仅MA60）、maCrossVolume（放量1.5）、maCrossBalanced（趋势+放量/RSI55）、maCrossStrict（趋势+放量+ADX/RSI50），买卖公式同金叉、过滤包固定，供回测下拉对比；不改原版 MaCrossStrategy。纸面扫描仍用配置激活。列表见 GET /api/config/strategies
  • 金叉首开：上一根 MA5≤MA20，本根 MA5>MA20（收盘确认；单股引擎有效回测通常需 K 线约≥65 根）
  • 必过过滤：RSI14 < 60；ATR14 > 0.001； 硬过滤（可关 market-cap-filter-enabled）：模拟市值 < 50 亿 → 直接跳过、不开仓
  • 可选过滤（yml 默认关）： MA60 上行（仅 ma60[i]≥ma60[i-1]，不要求价在 MA60 上方）； 放量 > 20 日均量×1.2； ADX：须 ADX ≥ adx-min(25) 且 ADX ≥ adx-chop-max(20)（低于 chop 视为震荡拒单）
  • 金字塔加仓（默认开）：该票浮盈≥1%（相对综合成本）且 MA5>MA20、总仓≤80%； 不重验 RSI/ATR；仅成交成功后占档（50%→30%→20%）
  • 金字塔切片：相对「目标满仓」50%/30%/20%；若首批不足 1 手但满仓目标≥100 股 → 抬到 100 股
  • 同日约束（按股票）：该票当日已加仓成交 → 不再受理首开；首开成交当日也不会再挂同日加仓
  • 该票已有未成交买单时，不再挂新买单

三、买入数量怎么算

  • 目标满仓股数 = 可用资金 × 单只上限30% × ATR调节 × 账户仓位系数 ÷ 现价，取整到 100 股
  • ATR调节 = baseAtr(0.05) ÷ 当前ATR，再夹到 [0.2, 1.5]
  • 账户仓位系数（峰值回撤）：<15%→1.0；≥15%且<25%→0.5；≥25%→0
  • 总仓：持仓市值 + 拟买入额 ≤ 总权益 × 80%
  • ATR 缺失：单股/组合/实盘 NaN 时均回退为 baseAtr(0.05)

四、卖出何时触发

  • 死叉：挂卖 → 下一有效撮合卖出该标的全部持仓（含今仓，不受 T+1 限制）；已挂卖不刷新信号日
  • 同日优先级（回测，预注册 ExitPriority）： 止损/trail（当根，rank100）> 回撤熔断挂卖（rank80）> 时间止损挂卖（rank70）> 死叉挂卖（rank40）； 若当日已止损清仓（stoppedOutToday）或已有挂卖 → 忽略同日死叉
  • 时间止损：quant.max-hold-trading-days（默认 0=关）；自最早开仓日后计交易日，达阈挂清仓；不受 ADV 参与率限制
  • 止损线 = max(成本−2×ATR, 成本−权益×2%/股数)，只上移
  • T+1（仅止损/trail）：仅 openDate < 今日 的老仓可卖；可部分卖出（只卖可卖手数）；未全清时保留今仓并重算止损线（单股引擎）
  • 止损跳空成交价（P0-115）： 若开盘价≤止损线（跳空穿价）→ 基准=开盘价； 否则盘中最低触及 → 基准=止损价；再套卖滑点/冲击。 （旧逻辑 max(止损,low) 在跳空时偏乐观，已废弃）
  • 移动止盈：盘后 trail = 持仓最高 − 1.5×ATR（只上移）；次日盘中老仓最低价触及判定
  • 跌停：相对昨收；挂卖连续 3 个交易日失败后按跌停价×0.99 强平
  • 回撤熔断（深度）：峰值回撤≥25% → 挂清仓且禁新开；本轮粘性（回测结束或进程重启前不自动解除）
  • 回撤持续期（P0-122）：权益低于峰值满 drawdown-duration-reduce-days（默认 10）交易日 → 仓位×0.5； 满 drawdown-duration-halt-days（默认 30）→ 持续期熔断（原因 DURATION）；创新高清零计数；单项 0=关闭
  • 策略退役（P0-92）：持续期熔断且 auto-retire-on-duration-halt=true 时自动退役禁新开； 冷却 retirement-cooldown-trading-days（默认 20）后可 resume；页面可手动退役/强制恢复
  • 告警分级冷却（P0-97）：软预算 WARN（总仓默认 70% / 单票 25%，相对权益；硬顶仍为 max-total/single）； 熔断/退役 CRITICAL；冷却窗内同类去重（WARN 默认 240 分 / CRITICAL 60 分）； GET /api/account/alerts；硬拦截仍由仓位与熔断逻辑执行
  • 信号漂移（P0-90）：滚动胜率（闭环回合）+ MA5/MA20 价差 vs 次日收益代理 IC（真因子 IC 不可用）；低于阈连续确认后 CRITICAL； auto-retire-on-signal-drift 默认 false；GET /api/account/signal-drift；不改金叉、不报复满仓
  • 行情自洽闸（P0-107）：检查 market_1min 空/滞后/稀疏日/OHLC；超阈告警； data-reconcile-block-on-diverge 默认 false；开启后阻断新开；GET/POST /api/ops/data-reconcile*；外部双源仍待 API
  • 结构突变（P0-120）：双窗收益均值差/波动；超阈确认后仓位×0.5 并挂漂移；GET /api/account/structural-break；不改金叉
  • ST as-of（P0-101）：优先 st_status_hist 日切；无行回退 stock_basic.is_st（有前视风险）； st-open-filter-enabled 默认 true 禁开；涨跌幅按 as-of ST 规则；财报公告时钟本地无数据，事件沙箱不进金叉
  • 换手 + 印花税 as-of（P0-104）：日换手=成交额合计/权益；软顶默认 50%→仓位×0.5，硬顶 100%→禁开； 卖出印花税按成交日（2023-08-28 前千一、起万一）；GET /api/account/turnover
  • 行业 reclass（P0-121）：industry_reclass_log as-of；选股中性用当时行业；不并金叉； GET/POST /api/ops/industry-reclass*
  • IC 衰减（P0-125）：滚动 IC（与信号漂移同源 MA 价差代理）估半衰期/IR；触发后仓位×0.5； GET /api/account/ic-decay；真因子 IC 仍待；不改金叉
  • 实验种子（P0-93）：quant.experiment-seed 写入 configFingerprint；默认空；不影响撮合随机
  • ATR 一体验收（P0-108）：定仓 ATR 调节夹紧 0.2~1.5；止损线=max(成本−atrMult×ATR, 成本−权益×hardPct/股)； 移动止盈只上移；回测结果带 atrRisk（含 stopExitEvents）
  • 信号漂移 IC 边界（P0-90）：icSource=MA_SPREAD_PROXY；factorIcStatus=UNAVAILABLE （factor_daily 仅为技术缓存，不作截面 alpha IC）；Kill 不改金叉
  • 禁空头（P0-102）：多头现货；卖出≤持仓；无融券开关；GET /api/account/short-policy
  • 限价保护边界（P0-94）：涨跌停夹紧可用；五档/L2=UNAVAILABLE； GET /api/account/order-protect
  • 执行降频边界（P0-112）：单股+组合均 AUM 收紧 ADV + 当根量 POV；TWAP=UNAVAILABLE； GET /api/account/execution-cap
  • 多源/行业外部源（P0-107/121）：本地日线↔分钟聚合 / 行业日志已具备； externalVendorSource / externalIndustrySource=UNAVAILABLE
  • 组合↔单股对齐：组合回测已挂部成残量、成交时仓位系数缩量、停牌拒卖、AUM+POV、ADV断崖/结构突变×0.5、 ST as-of 限价/跌停强平、结果 atrRisk；实盘另有换手/IC衰减（纸面对账 ENGINE_PATH）
  • 退役双人复核（P0-92）：force=true 先武装 forceConfirmToken， 第二人带 confirmCode 再恢复；冷却满可直接 resume
  • 风控日报（页面）：账户 →「风控日报」聚合 /api/account/alerts|turnover|ic-decay|signal-drift|… 只读状态

五、撮合与成本

  • 日K/周月（默认 next-bar-open-fill=true）：收盘信号 → 下一根开盘价
  • 分钟序列：开仓/死叉在信号日次日且 bar≥09:45 的第一根可用 K
  • next-bar-open-fill=false：买/卖按当根收盘价撮合（绕过次日开盘逻辑）
  • 静默（仅分钟序列挂新开信号时生效；日 K 无静默）：09:30–09:45、14:45–15:00
  • 撮合步内顺序：先处理卖单，再处理买单
  • 例外：老仓止损/trail 按触及价当根卖
  • 买单超过信号日 +5 日历日未成交 → 取消
  • 买单过滤未成交时挂单保留：熔断/静默/开仓过滤等仅记 REJECT，不清空挂单，可跨 bar/跨日重试，直至成交、现金不足取消、止损清仓取消或过期
  • 佣金万三（最低 5 元）；印花税千一（仅卖）
  • 分级滑点（近20均量）：≥2000万→0.05%；≥500万→0.2%；否则→0.5%
  • 冲击：min(0.1×本笔量/20日均量, 2%)；买上浮、卖下浮，与滑点叠加
  • ADV 参与率硬顶：单笔量 ≤ 近20日均量 × quant.max-participation-adv（默认 0.10）；买入与死叉卖出受限，不足1手则挂单保留；止损/熔断/时间止损卖出不受限；≤0 关闭
  • 扩容降频 + POV（P0-112）：权益超过 capacity-aum-base（默认 100000）时按比例收紧 ADV 顶；另可选 pov-max-bar-volume-pct（默认 0.10）限制单笔≤当根量×比例；只降频不改金叉
  • 限价保护（P0-94）：quant.limit-price-protect-enabled（默认 true）时，成交价买≤涨停、卖≥跌停夹紧；无本地五档，完整 L2 保护仍待行情源
  • 回测部成 / 改价撤补（P0-95）：quant.backtest-fill-ratio（默认 1=满额）；<1 时买单按比例成交、残量挂单保留； 部成率见 GET /api/account/partial-fill；实盘改价=POST /api/account/orders/{id}/replace（撤旧+新单，队尾重置，不保优先级）
  • 压力情景（P0-96）：预注册 ADV 断崖（adv20/adv60<stress-adv-cliff-ratio 默认 0.40 → 仓位×0.5）、一字板告警、相关尖峰、回撤政权；只降仓/告警，不改金叉；GET /api/account/stress
  • quant.slip-point：仅做入参合法性校验（≥0），不参与成交定价；真实滑点以分级滑点为准
  • 滑点残差日报（P0-99）：GET /api/account/slippage-residual 对照委托价与费用模型；纸面对账摘要带平均不利 bp；不自动回写改价/滑点配置
  • 回测结果字段 configFingerprint（格式 v1:<16hex>）摘要策略相关配置，历史表可落 config_fingerprint

六、开仓过滤与账户风控

  • 涨跌停（相对上一交易日收盘；分钟序列不取相邻 bar）： 主板 ±10% / 创科 ±20%； 软阈值：收盘触及昨收×(1±限幅×0.95) 即判； 或 OHLC 均贴齐限价 ±0.01（封板）
  • 停牌量≤0 → 禁止开仓；挂卖/止损亦拒成（挂单保留至复牌）；持仓复牌无「首日必卖」专项规则
  • 低流动性：近20均量 < min-avg-volume20（演示默认 1000）→ 不开
  • 模拟流通市值 = 现价 × 流通股本(亿股)；未配置时启发式股本： 代码 6*→120、3*→80、688*→40、其它→100； 可用 quant.float-shares-yi.<code> 覆盖；阈值默认 50 亿
  • 单日亏≥昨收权益的 3% → 当日禁新开
  • 连亏 5 笔完整开平 → 当日禁开、次日自动恢复
  • 回撤≥15% 仓位×0.5；≥25% 禁开+清仓挂单

七、买单/卖单未能成交的常见原因

  • 账户熔断禁开 / 单日亏损禁开 / 连亏禁开
  • 开盘静默 09:30–09:45 禁止新开成交（分钟路径）
  • 开仓过滤未过：涨跌停（含 0.95 软阈值）、停牌、流动性、市值、收盘静默等——此时挂单仍在，可稍后重试
  • 加仓时涨停或停牌（单股）；组合/实盘加仓另见差异节
  • 现金不足，或买入后突破总仓 80% → 取消挂单
  • 仓位系数缩放后不足 1 手（100股）→ 取消挂单（单股/组合/实盘一致）
  • 卖出遇跌停：累计失败，满 3 个交易日后按ST as-of 跌停价×0.99 强平
  • 卖出遇停牌（量≤0）→ 本日不成交，挂卖保留
  • 买单超过信号日+5 日历日 → 过期取消

八、单只回测（页面「个股回测」）

  • 工作台选股仅来自目标池（trade_pool）；池空需先「扫描更新」。行情浏览仍为全市场
  • 默认周期 DAY；起止时间留空 = 该股全量可用 K 线（由 market_1min 聚合）；非 DAY 周期同样由 1 分钟聚合；页面默认工作台仍为 DAY
  • 初始资金默认 100000（可改）
  • K 线 < 65 根 → 返回空结果
  • 决策顺序：①撮合挂单（先卖后买）→ ②老仓止损/trail → ③账户风控 → ④收盘挂金叉/金字塔/死叉 → ⑤盘后更新 trail
  • 首开/金叉买单成交：走完整 canExecuteOpenFill；加仓成交：仅拦涨停/停牌
  • 成交股数 = 挂单股 × 当前仓位系数 后再取整手
  • 结果含：权益曲线、买卖点、成交明细、tradeStats、决策分析事件
  • 历史与分析一一对应，写入 MySQL：bt_backtest_record / bt_backtest_analysis

九、组合回测（多股共享资金池）

  • 工作台内仅从目标池搜索多选成分股；共用一份现金与同一套账户风控（熔断/连亏/单日亏/仓位系数）
  • 强制用 DAY 行情；按各股交易日并集时间轴推进；某股当日无 K 则跳过该股
  • 单股 K 线不足约 65 根则不进入组合
  • 每只股票独立：持仓 lot、金字塔档位、挂单、止损/trail、stoppedOutToday
  • 买入手数仍受单只30%与总仓80%约束（相对组合总权益；挂单时已用仓位系数算目标量）
  • 与单股差异：
    • 加仓成交也走完整 canExecuteOpenFill（流动性/市值/静默等），不只拦涨停/停牌
    • 成交股数 = 挂单股 × 当前仓位系数 后再取整手（与单股一致）；挂买成交时再查熔断/allowNewOpen
    • ATR 无效回退 baseAtr（与单股一致）；部分止损后 raiseStopByCost（组合权益）
    • 跌停强平：连续失败 ≥3 日后按 ST as-of 跌停价×0.99 强制卖出（与单股/实盘一致）
  • 熔断时：对所有仍有持仓的成分股挂清仓
  • 分股表现：按该股已实现盈亏、买卖统计、该股维度回撤等汇总；贡献率≈该股已实现盈亏/初始资金
  • 历史/分析同样落库（kind=PORTFOLIO）

十、批量扫描（个股回测页「扫描」）

  • 对配置标的列表（默认 600036/000001/300059）线程池并发（池大小 batch-pool-size，默认 10）
  • 每只：全量 DAY K 线 + 初始资金 100000 跑一遍个股回测引擎
  • K 线 < 20 根 → 跳过该股；20–64 根会进列表，但引擎仍要求约≥65 根才有有效回测结果（中间区间多为空结果）
  • 额外计算最新指标与「当前是否金叉可买」信号描述，按总收益率降序展示
  • 扫描结果为即时列表，不单独写入回测历史表（除非你再点个股回测保存）

十一、实盘分钟扫描（运维任务，模拟现金）

  • 默认各任务关闭：配置在 MySQL sys_schedule_job（种子 enabled=0）；页面「运维中心 → 任务管理」可启停/改 cron，立即重载
  • 总闸 quant.schedule.enabled（默认 true）：为 false 时不注册任何触发器；目录见 GET /api/schedule
  • 唯一目标池：全市场经 pool-rebuild 或 after-market-batch-scan 盘后扫描自动覆盖 trade_pool；无需人工确认；扫描无入选时清空池
  • pool-rebuild 与 after-market-batch-scan 启用其一即可
  • 页面「目标池」可手动移出标的（移出≠卖出，不停仓）
  • 交易时段约每分钟扫描目标池内活跃标的（工作日 9–11、13–15 点）；模拟初始现金默认 100000
  • 规则意图对齐回测：金叉/金字塔/死叉、止损/trail、账户风控、09:45 撮合、跌停强平等
  • 已知差异：
    • 加仓成交走完整开仓过滤（同组合；单股金字塔撮合过滤更松）
    • RiskControlService#checkBuy 无 K 线时退回墙钟交易时段（含静默），并校验持仓后单票市值 ≤ 权益×30%×仓位系数
    • 网关数量账本与策略批次账本双路径；已用成交后同步与启动恢复对齐，异常时以批次为准
    • sdk 同步仍为本地桩（不看真实柜台），但重启会重建未完结委托与预留
