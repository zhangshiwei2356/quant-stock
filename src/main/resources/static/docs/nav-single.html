个股回测对一只股票按均线金叉策略做历史模拟，并给出买卖点、权益曲线与决策分析。

二级菜单说明

  • 回测工作台：目标池下拉直选或池内全量搜索；参数分标的/时间资金/策略；主按钮执行回测
  • 批量扫描：对股票池批量跑回测摘要，可筛「仅可买入」
  • 回测历史：查看落盘记录与分析；可勾选全部历史跨股查看

步骤怎么开始

  1. 确保目标池有标的后，点「回测工作台」，用下拉或搜索选定一只
  2. 按分组填好时间/资金与策略后点「执行回测」；需要时再进「批量扫描」或「回测历史」
