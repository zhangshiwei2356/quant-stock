应用说明收录启动方式、完整 README、交易规则与能力路线图，便于对照代码能力。与「量化知识」同属扩展与文档；宽睿联调见「宽睿对接」。

分组本菜单包含

  • 入门：系统概述（启动/模块摘要）· 项目 README（架构图与接口表）
  • 规则：交易规则（撮合、成本、仓位与风控，对齐回测/扫描）
  • 路线：能力与待办（待对接置顶；本地已落地可折叠）
  • 宽睿资料与联调入口见「扩展与文档 → 宽睿对接」

步骤怎么用

  1. 点「从系统概述开始」，或在左侧按分组点选
  2. 阅读区可快切四篇、上一篇/下一篇（← →）；长文有目录；交叉引用可点
  3. 改代码后核对「系统概述 / README / 能力与待办」是否仍准确；完整仓库说明优先看 README
