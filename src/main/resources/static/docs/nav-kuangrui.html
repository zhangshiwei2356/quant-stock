点测宽睿 OES/MDS 运维接口，查看入参 / 出参与接入开关状态。默认旁路关闭；报撤须 yml 打开 order-enabled 并二次确认。账号可在「账号登录」验柜后密文入库（优先于环境变量）。

二级菜单说明

  • 接入总览：账号凭据 / MDS / OES / order / static 状态一览
  • 账号登录：先连柜台验柜，成功后再加密落库；可查询当前生效账号；清除 active 回退 env
  • OES 只读：资金、持仓、委托、成交等；展示 HTTP 入参出参，可一键复制
  • MDS 行情：状态与静态查询；pull / subscribe / flush / stop；结果可一键复制
  • 报撤试单：限价买/卖/撤；仅 orderLive；弹框确认；出参可一键复制

步骤建议流程

  1. 确认 -Pkuangrui 与 config/kuangrui/local 通道配置
  2. 「账号登录」验柜入库，或设置 QUANT_KUANGRUI_USER / PASSWORD
  3. 先开 kuangrui.enabled + oes.enabled / mds.enabled 做只读点测
  4. 报撤另开 oes.order-enabled=true（仅 yml，非运行参数页）

再点一次「宽睿联调」可收起并回初始化页。手册见「应用说明 → 宽睿文档梳理」。
